# tasks/ — 통합가 → 작업자 묶음 과제

통합가(Opus/사람)가 작업자(수집가)에게 맡기는 **묶음(batch) 하나**를 여기 `TASK-<주제>.md` 로 적는다.
한 번에 하나 — 작업자가 그 묶음을 혼자 끝내고 `workspace/handoff/` 로 넘긴다(항목마다 핑퐁하지 않는다).

과제에 적을 것(수집가 프롬프트 `docs/PROMPTS.md` §3′ 와 같은 틀):
- **임무 한 줄**: 무엇을 수집·점검하나.
- **각 후보에 반드시**: 값·단위 · 종·세포·측정 시각·불확도 · 출처(DOI/PMID)+원문 인용 · 현재 use · "규약 가능? 빠진 것".
- **경계**: 읽기·조회만, `workspace/` 밖 쓰기·apply·commit·규칙 수정 금지, 지어내지 말고 못 찾으면 "없음".
- **반환**: `handoff/HANDOFF-<주제>.md` 표 + 3~5줄 판정.
