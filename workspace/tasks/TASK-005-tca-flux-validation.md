# TASK-005 — 사람 세포 TCA 흐름·중간물의 정량 측정 (종류 V)

먼저 `workspace/START-HERE.md` 와 `workspace/SOURCES.md` 를 읽어라.

**왜**: TCA 정량 검증 실험(`docs/design/tca-validation-protocol.md`)은 모델이 **(가) 기질 중간물 정상 상태 농도**와 **(나) 회로 흐름**을 맞히는지 본다. 예측과 견줄 **검증 측정**이 지금 하나도 없다(정량 관찰 22 개가 전부 입력용). 입력 쪽 대사물은 Chen 2016(PMID 27565352, HeLa 기질 대사물 절대 정량)에서 나오므로, **같은 논문이 아닌** 측정이 특히 필요하다(L000124).

**대상**: 경로 `D000148` · 한계 L000121(보충·유출) · L000124(입력과 예측이 같은 실험).

**임무 — 사람(9606) 세포, 가능하면 HeLa**

| 칸 | 무엇 | 조건 |
|---|---|---|
| B1 | TCA 흐름의 직접 측정 — ¹³C 동위원소 흐름 분석(MFA)의 회로 흐름 값 | 세포·배지·단위(세포당·단백질당) 그대로 |
| B2 | 산소 소비 속도(OCR) 또는 CO₂ 생성 속도 | 원값만 — P/O 같은 환산을 하지 마라 |
| B3 | 기질(또는 세포 전체) TCA 중간물 농도를 Chen 2016 과 **다른 연구실·다른 방법**으로 잰 값 | 시트르산·아이소시트르산·2-옥소글루타르산·석시닐-CoA·석신산·푸마르산·말산·옥살로아세트산 중 무엇이든 |
| B4 | 글루타민 유입(→ 2-옥소글루타르산)·시트르산 유출 흐름 | 같은 세포 |
