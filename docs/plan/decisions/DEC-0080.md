# DEC-0080 — SUP-0001 취소 — r3 author 변경은 다시 검수하지 않고 PLAN-112 주장 층 시범으로 흡수 (DEC-0074)

> 생성물 — 원본 `rebuild/state/plans.jsonl` · `rebuild/state/plan-log.jsonl` 에서 (`node rebuild/status.mjs --write`). 손으로 고치지 않는다 — 바꾸려면 `node rebuild/plan.mjs apply`. 계획: [build](../build.md)

`2026-11-23` · 사용자 (세션 답 2026-11-23 '순서대로 하자' (선택표의 첫 줄 · 권고를 고름 — 통합가가 그렇게 읽음)) · 순서

사용자: "순서대로 하자" — 직전 보고의 선택표(취소 — 권고 / 다시 검수)와 우선순위 목록의 차례로 읽음. 까닭: G3 적용 뒤 SUP-0001 r2 독립성은 full 이지만 최종 권고 hold — 검수 뒤 r3 author 변경(설계 지시서 등록 · DEC-0073 기록 · 순서 변경, 데이터 · 패치 · 한계는 건드리지 않음)이 검수되지 않음(RULE-0543). P1 수정 권고는 DEC-0074 로 PLAN-112 주장 층 시범에 흡수하기로 했으므로 r3 를 다시 검수할 일이 남지 않는다. 취소는 감독 장부 cancel 사건(이 결정 번호)으로 — 기록은 지우지 않음. P1 패치(data, 커밋 178c43a)는 DEC-0073 대로 그대로 병합하지 않음 — 이 브랜치를 main 에 넣을 때 처리는 별도 결정.
