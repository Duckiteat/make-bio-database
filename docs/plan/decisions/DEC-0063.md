# DEC-0063 — 엔진을 하나로 할 때 시작량은 명시만 허용 · 보조 입력이 0 이면 엔진이 그 단계를 막는다

> 생성물 — 원본 `rebuild/state/plans.jsonl` · `rebuild/state/plan-log.jsonl` 에서 (`node rebuild/status.mjs --write`). 손으로 고치지 않는다 — 바꾸려면 `node rebuild/plan.mjs apply`. 계획: [build](../build.md)

`2026-11-19` · 사용자 (세션 답 2026-11-19 (선택지 그대로)) · 설계

제안(PLAN-055 측정 docs/reports/2026-11-19-two-engine-gap.md): 두 엔진 차이의 대부분이 시작량 기본값(속도 엔진은 세포 기본값 · 대사물 풀, 운명 엔진은 0)이고, lps-tnf-validation 운명 실행은 ATP 0 에서 보조 입력 소비가 멈추지 않아 음수 거부를 되풀이한다. 답: ① 시작량 기본값 — "명시만 허용 (권장)": 주지 않은 시작량은 0 이 아니라 '없음'으로 보고하고 경고 · 거부, 숨은 기본값을 없앤다(기존 cAMP · TCA · LPS 시나리오에 시작량을 적는 데이터 작업이 따름 — PLAN-080 에서). ② ATP 병리 — "엔진: 보조 입력 막기 (권장)": 보조 입력이 화학량보다 적으면 그 단계 속도를 줄여 0 에서 멈춘다(코드, NUMERICAL).
