## 결과 (날짜별)

- `2026-10-30` 커밋 전 기록: 2026-10-30: 지도는 손으로 쓰지 않고 추적에서 계산 — tests/trace.mjs 가 시험 파일마다 실제로 읽은 저장소 파일(모듈 적재 · fs · 폴더 목록 · 하위 프로세스 · 워커, 저장소 안 git 은 역사 표시)을 모으고, tests/affected.mjs 가 시험마다 '마지막으로 통과했을 때의 작업 파일 스냅숏(tests/snapshot.mjs) 이후 그 시험이 읽은 것이 바뀌었나' 로 고른다. 지도가 없거나 시험이 지도에 없으면 돌림, 새 파일은 그 폴더를 목록으로 읽은 시험이 잡음. 지도는 저장소 밖(서기 초안) — 계획의 '지도 없는 파일이면 전체' 는 '지도 없는 시험이면 그 시험' 으로 더 좁게. push 는 문지기 finish --full 뒤에만(RULE-0516 확장): 전체 + 추적 구멍 검사(건너뛸 수 있었던 시험이 지도에 없는 것을 읽으면 실패 — 끝나는 조건 '빠진 연결을 넣으면 잡음'). 확인: tests/affected.test.mjs(합성 기록 + 임시 저장소 끝까지, 지도에서 뺀 연결을 --full 이 잡음) · gate ②(닿는 시험만이면 커밋만, push 는 --full) · 실제 저장소 전체 추적 시간 207 s(추적 없이 193–225 s)
