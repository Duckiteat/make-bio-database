FMA 방지: `build.sh` 가 네이티브 FMA 명령과 WASM SIMD 를 검사해 있으면 실패 (target-cpu=native 로 일부러 켜서 가드가 막는 것 확인). 결과: **JS = Rust 비트 일치 26/26 시나리오** (이전 1/26, 확률 실행 포함), 수정 전 대비 결정론 24 개는 궤적 상대차 ≤ 2.1e-9 (rtol 1e-6 의 1/400), 도달 시각 ≤ 1.8e-6 s, 결정 시각 ≤ 2.3e-12 s, 사건 순서 · 끝 상태 모두 같음. 확률 실행 2 개는 이산 결정이 갈려 경로가 바뀜(같은 분포). 남음: `core.js`(속도 엔진)·`model.js`·`ir_builder.js`(컴파일 단계 상수)·`judicial/`·JS 앞단(`distance` 분류 등)은 아직 `Math.*` 를 씀 — 두 백엔드에 같은 값이 가거나 JS 에서만 도는 곳이라 일치 문제는 없음. 속도 엔진은 PLAN-080, 컴파일 단계의 정확한 유리수 원칙은 ASY-08 의 몫.
