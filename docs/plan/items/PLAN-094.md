- **작업**: **실행 인터페이스 (읽기 전용 MCP)** — `fate`(운명 엔진) · 앙상블 · 속도 엔진 실행을 MCP 도구로 연다. 엔진은 저장소를 바꾸지 않으므로 조회와 같은 읽기 전용. 결과에 입력 지문(데이터베이스 · 시나리오 · IR 해시) · 등급 · 가정 의존(가상/실측 상수 수) · 한계 표시를 붙인다. 인공간뇌가 시나리오를 만들어 돌리고 예측을 받는 길 (`docs/reports/2026-11-02-brain-source-sufficiency.md` §2 C2)
- **자리**: `mcp/`(새 읽기 전용 도구 또는 `query.mjs` 확장) · `orchestrator.js` · 거버넌스 시험(쓰기 없음)
- **끝나는 조건**: 도구 목록 시험(쓰기 · 파일 생성 없음) · 같은 입력 같은 출력 해시 · 출력에 등급 · 가정 의존 표시 · 규약 없는 실행은 '탐색' 표시
- **상태**: ☑ 완료 2026-11-18
