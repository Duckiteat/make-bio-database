## 결과 (날짜별)

- `2026-11-02` 커밋 전 기록: 엔진 쪽 완료 — 카운터 기반 난수 (JS `engine/rng.js` · Rust `engine/rust/src/rng.rs`, WASM 다시 빌드). 난수 하나 = (seed, 궤적, 흐름, 번호, 부번호) 의 순수 함수(splitmix64 마무리 네 번). 흐름 = 2·전역 규칙 번호 + 종류(0 SSA 지수 · 1 도약 포아송), 번호는 엔진이 규칙·종류마다 세고 거부된 도약은 되돌림 → 줄 서서 뽑다 걸음 이력에 밀리던 문제(시드 표류) 제거. 비트 연속성 한 번 단절: 결정론 시나리오 46 지문(23 시나리오 × JS·Rust)은 수정 전과 비트 동일, 확률 실행 3 시나리오(mhc-dc-maturation-stochastic · stochastic-mixed-optimal · telomere-stochastic-attrition)의 궤적은 바뀜. 확인: 해석해 시험(출생–사멸 pmf)·방식 비교·결정론 극한·출생–사멸 JS = Rust 비트·네이티브 = WASM 비트 통과, 난수 모듈 순수 함수·균등·포아송 분포 시험(④b). 남음: (1) 공통 난수 짝 판정(사법부 `stoch_audit` — 같은 (seed, 궤적) 쌍으로 변형 A·B 를 짝지어 비교하는 판정과 검정력 시험)은 사법부 규칙이라 요청이 있을 때 (2) 도약의 번호는 규칙마다 걸음 순서로 매겨져, 허용 오차가 다르면 같은 번호가 다른 구간에 쓰임 — 완전한 구간 단위 공통 난수는 아님 (3) 확률 실행의 JS 와 Rust 는 끝 상태가 같은 분포이지만 비트 동일하지 않음(libm — PLAN-021).
