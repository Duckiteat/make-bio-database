# 측정법 계획 — 기초 판독에서 조합·심화로 (만든 방법을 남기며)

> 생성물 — `node rebuild/status.mjs --write` 가 원본 `rebuild/state/plans.jsonl` · `rebuild/state/plan-log.jsonl` 에서 만든다. 손으로 고치지 않는다.
> 바꾸려면 `node rebuild/plan.mjs apply <ops.json>` (바꿀 때마다 왜를 적는다). 하나만 읽기: `node rebuild/read.mjs <PLAN-…|STG-…|DEC-…|DIR-…|ASY-…> [--depth 0|1|2]`.
> 이 문서의 차례: 목적 → 왜 → 결정(표) → 작업(표) → 종합 결과와 의의 → 나아갈 방향 → 열린 질문 → 근거 점검. 무엇을 언제 하나는 [순서](ORDER.md), 작업 하나는 items/, 결정 하나는 decisions/.

> 측정법을 판독 방식 단위로 세운다 — 분리법(크로마토그래피·전기영동)은 판독의 앞 단계 속성. 앞 단계의 판독을 뒤 단계가 조합한다. 측정법마다 무엇을 보고 어떻게 정했는지(만든 방법 · 버린 대안 · 근거 출처)를 장부에 남긴다.
> 어휘는 그 단계의 방식으로 잰 실제 관찰이 들어올 때 연다 — 쓰지 않는 항목을 미리 짓지 않는다(RULE-0462).
