# 엔진 이식 로드맵 — Rust/WASM 행정부 · 기호 야코비안 · 이산 확률론

> 지위: 확정된 계획 (2026-10-09). 단계마다 완료 조건을 통과해야 다음 단계로 간다. 삼권 분립(`tripartite-governance.md`)이 전제다.
> 바꾸는 것은 행정부(엔진)뿐이다. JS 사법부는 그대로 남아 새 엔진을 독립적으로 검증한다. JS 엔진은 기준 구현(오라클)으로 보관한다.

## 1. 불변 조건

- **권력 분리**
  - 컴파일러 `compiler/ir_builder.js`
    - 순수 함수다: db + 시나리오 → 불변 IR (정수 번호, 화학량 S, ∂rate/∂N 기호식, 희소 패턴, 버퍼 크기).
    - 쓰기·판정·엔진 호출을 하지 않는다.
    - IR 해시는 무결성 증명서의 입력 해시에 들어간다.
  - 사법부 `judicial/`
    - 미분 검사, 원자료 계약, 질량·재생 검증, 앙상블 통계 검정을 맡는다.
    - 실행에 참여하지 않는다. IR 을 만들지도 않는다.
  - 행정부
    - `engine/rust/` (네이티브 C-FFI + WASM) 는 IR 을 받아 원자료만 낸다.
- **원자료 계약**
  - 어느 엔진이든 `schemas/ffi/fate-raw.schema.json` 을 지킨다.
  - `judicial/contract.js` 가 형·필드·배열 길이(`x-dimensions`)·묶음 참조를 검사한다. 어기면 판정하지 않는다.
  - 판결 필드(`audit`·`postMortem`·`arrest`·`mass.worst`·`process.hash`)는 계약상 금지다.
- **할당 0**
  - 모든 버퍼 크기(묶음·규칙·nnz·기록점·탐침 스냅숏)는 IR 이 정한다.
  - 엔진은 처음에 한 번만 할당한다.
  - WASM `memory.buffer.byteLength` 가 실행 내내 변하지 않아야 한다. 그래야 JS 쪽 `Float64Array` 뷰가 무효(detach)가 되지 않는다.
  - 아레나 할당기는 프로파일이 필요를 보일 때만 쓴다. 고정 크기 미리 할당이 기본이다.
- **결정론**

| 비교 | 기준 |
|---|---|
| 같은 엔진 다시 실행 | 비트 일치 (궤적 해시) |
| 엔진 사이 (JS ↔ Rust) | 허용 오차: 원장·재생 ≤ 1e-14(각 엔진의 자기 일관성), 궤적 상대 ≤ 적분 허용 오차 rtol(1.5단계부터 — 적응 단계의 받아들임·거부가 libm 마지막 ulp 로 갈릴 수 있음, 1단계 분할 엔진은 ≤ 1e-9), 운명·도달·결정 시각이 같을 것(Δt 이내) |
| FMA | Rust 는 기본으로 FMA 를 쓰지 않는다(명시 호출만). TwoProduct 는 같은 식을 쓴다. |
| 확률론 | 고정 PRNG(`xoshiro256++`, 명세를 문서에 고정), 고정 seed 목록, 고정 α, Holm 보정 → CI 판정이 결정론적 |

### 수학적 경계 처리 (0.5)

- **힐, n < 1**: s → 0⁺ 에서 도함수가 무한대가 된다. IR 이 s_min(결합점 등록부)으로 기울기를 자른다. 미분 검사는 자른 식 그대로를 검증한다.
- **완충 `min(c0, c)`·`max(0, N)`**: 잔차는 그대로(엔진 의미 불변) 두고, 야코비안은 현재 반복점에서 활성인 가지의 도함수를 쓴다(준-매끄러운 뉴턴). 완충 상한 위·N ≤ 0 이면 ∂c/∂N = 0. 진동이 관찰되면 그때 가지 고정을 넣는다 (지금 8 시나리오에서 뉴턴 실패 0).
- **1차 분해의 정확한 지수 갱신**: 빠른 층 명시 경로에만 쓰고, 해석적 J 에는 1차 항 k·N 의 도함수를 넣는다.

- `compiler/ir_builder.js`

### 군더더기 금지 (Zero-Bloat)

- 결함은 그 노드(`docs/textbook/storage-map.json` 의 `node`·`governance`·`refactor_strategy`) 안에서 고친다.
- 래퍼·임시 대체 플래그를 쓰지 않는다.
  - 0.5단계의 유한차분 경로는 판정 뒤 제거했다.
  - 뉴턴 실패 → 명시 대체, P5 관문, 명시 부분 단계는 1.5단계 판정(§7) 뒤 두 백엔드에서 제거했다.
