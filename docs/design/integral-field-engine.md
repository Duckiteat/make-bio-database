## 0. 한 줄 요약

장(場)은 **적분형**으로 돈다. 칸 값은 공간 적분(정수 분자 수)이고, 갱신은 면 유속의 적분과 정확 적분 핵이다. 계산 밀도는 분포가 바뀌는 칸에서만 올라간다(스파크). 비싼 적분 핵은 입력 해시로 보관해, 처음엔 계산하고 그 뒤로는 찾는다. 도함수·야코비안은 스파크 안 T2 국소 계산에만 남는다.

## 1. 원칙

1. **적분형, 미분형 아님.** 상태 = 칸 안의 양 ∫_cell c dV. 갱신 = Σ 면 유속 ∫Δt + 칸 안 정확 적분. 기호 도함수·LU 는 장에 쓰지 않는다.
2. **보존량은 정수.** 칸 값·원장·델타 누적은 정수(블록 고정소수, §4). 한 칸에서 뺀 정수를 옆 칸에 더하므로 수지는 구조상 정확(근사 1e-14 가 아니라 0).
3. **계산이 만든 진동을 0 으로.** 목표는 확률 진동의 *물리적 폭*을 줄이는 것이 아니다(~1/√N, 그것은 결과다). 부동소수점이 만드는 가짜 분기(문턱 근처 1 ulp → 다른 추첨)와 치우침(작은 델타 소실)을 없애서, 남은 진동이 전부 물리임을 보이는 것이다.
4. **상수는 한 번 접는다.** 단위 환산·SI 정확 상수·부피는 컴파일 때 정확한 유리수로 묶고 f64 로 한 번만 반올림(§4.3).
5. **기록은 파라미터, 계산은 보관 사본.** db 에는 측정 자릿수 + 분포(관찰 O…)만. 계산 결과는 입력 해시가 열쇠인 다시 만들 수 있는 사본(T5)이고 원본과 섞이지 않는다.
6. **층 사이 벽.** 데이터: 법칙(`vocab`) → 성질(D, T1·T2) → 상호작용(규칙). 아래는 위를 참조하지 못한다. 실행: T3·T4·T5 는 db 에 들어가지 않는다(`vocab.tiers.T3` 의 "영역 상태 전용" 원칙의 확장).

## 2. 층

| 층 | 역할 | 이미 있는 씨앗 | 바꿀 것 |
|---|---|---|---|
| T1·T2 (데이터) | 성질·규칙 행위자 | 정의항 `tier` | 없음 |
| **T3 확률장** | 4차원 격자 (x, y, z, 배제 부류 e). 칸 값 = 정수 분자 수. 확산 = 면 유속 적분, 반응 = 정확 적분 `n(1−e^{−kΔt})` | `fv_solver.js`(보존형 면 유속·정확 반응 적분) · `hmse.js`(정수 원장·거래, `sampleTransferFixed` 1e-9 고정소수 이월) · 기준 경계 마스크 5종 | 장을 실수 + 원장 재척도 → **장 자체 정수**(재척도 제거). 0/1 마스크 → **배제 축 e** (§6) |
| **T4 스파크** | 분포 변화가 문턱을 넘는 칸만 촘촘히. 막 2차원·필라멘트 1차원으로 낮춤. 칸 안에서만 T2 행위자·확률 추첨 | `p5_dynamic_gate.js`(승격·강등·히스테리시스·냉각·전이 원장 일치) · `hmse.domainScore`(라플라시안 + 공간 엔트로피 변화율) · `decideTransition` | 판정 기준 **강성 N_sub → 분포 변화**(엔트로피 변화율, 국소 KL, 분자 수 적은 칸의 Fano). 이 문턱 = 거친 핵의 **유효 범위** |
| **T5 핵 기억** | 적분 핵·전파자·접은 상수를 입력 해시로 보관·조회 | `fno_surrogate.js`(닫힌 상자에서 FV 라플라시안이 DCT-II 대각 → 모드별 e^{−λ_k DΔt}) · `ood_detector.js` | 최소 제곱 **학습 근사 → 정확 핵 표**. 표 밖(모양·이류·충격) = OOD → T3 직접 계산 |

"직선 운동일 때 차원 축소" 는 쓰지 않는다 — 세포 안 분자는 ps 이후 브라운 운동이라 조건이 거의 성립하지 않는다. 대신 **장의 국소 구조가 저차원**인 곳(막 = 2D, 필라멘트·DNA = 1D, 기울기가 한 축에 쏠린 곳)에서 낮춘다.

## 3. 한 거시 단계

1. **T5 조회** — 열쇠 = hash(D, Δt, h, 모양, e, 양자). 있으면 핵을 꺼내고, 없으면 계산해 보관한다.
2. **T3 적분** — 모든 칸에 핵을 적용한다(확산 = 핵 합성곱, 반응 = 정확 적분). 델타는 정수로 누적하고 양자 미만은 잔여 누산기로 이월한다. 연속 배열에서 분기 없이 돌아 SIMD 대상이다.
3. **T4 판정** — 칸별 분포 변화량이 τ_high 를 넘으면 스파크(히스테리시스·최소 체류는 P5 그대로). 스파크 칸만 저차원·촘촘한 적분·추첨으로 다시 계산한다.
4. **경계 거래** — 스파크 ↔ 장의 출입은 정수 거래(`applyLedgerTx`·`applyLocalTx`)로만. Σ칸 = N_ledger 는 정확히 같아야 한다.

## 4. 수치 표현

### 4.1 자리 예산
필요 비트 ≈ log₂(동적 범위) + log₂(1/목표 상대오차) + ½·log₂(누적 단계) + log₂(적층 층수) + 여유.

| 양 | 범위 | 목표 | 단계 10⁸ | 합 | int64 |
|---|---|---|---|---|---|
| 분자 수, 전역 축척 하나 | 1–10¹² (40) | 1e-6 분자 (20) | 14 | ~76 | ✗ |
| 같은 양, 종·층별 축척 | 10⁶ (20) | 20 | 14 | ~56 | ✓ |
| 농도, 축척 하나 | 1e-12–1 M (40) | 20 | 14 | ~76 | ✗ |

→ **블록 고정소수**: 블록(종 × 층) 안은 i64 정수, 블록마다 축척 하나. 축척·양자는 결합점 등록부(`engine/coupling.js` 계열)에 선언한다. 사법부는 범위 초과와 양자 미만 소실을 검사한다. 4차원은 칸 수를 늘릴 뿐 칸당 자리를 거의 늘리지 않는다.

### 4.2 형식 배치

| 자리 | 형식 |
|---|---|
| 칸 상태 · 원장 · 델타 누적 | i64 (블록 축척) + 잔여 누산기 |
| 칸들을 모으는 합 (층 합산, 전체 수지) | i128 |
| 적분기 내부 · exp·pow · 핵 계수 | f64 |
| 상수 접기 (컴파일 시점) | BigInt / 정확 유리수 → f64 한 번 |
| 루프 안 임의 정밀도 | 쓰지 않음 |
| JS 오라클 | BigInt64Array (느려도 Rust 와 비트 대조 가능). f64 안 정수(2^53)는 범위가 달라 쓰지 않음 |

### 4.3 상수
상수는 곱하는 값이라 정수화하지 않는다(고정소수 곱은 매번 축척 시프트·반올림이 생긴다). 정확한 유리수로 접고 f64 로 한 번 반올림한다. 지금 엔진의 첫 대상: `engine/rust/src/tape.rs` 농도 읽기 `n[i] / (na * vv)` → 묶음별 `1/(N_A·V)` 를 미리 계산(나눗셈 → 곱셈). 반올림 위치가 바뀌어 궤적 비트가 달라지므로 JS 오라클·컴파일러·`judicial/derivative.js` 재구성을 같은 커밋에서 맞춘다.

### 4.4 측정 (2026-10-15, 이 컨테이너, 참고값)

| 실험 | 결과 |
|---|---|
| JS 4M 배열 뺄셈 | f64 10.1 ms · i32 7.9 ms · i32 보수 덧셈 `a+(~b+1)` 8.9 ms(**더 느림**) · BigInt 31.8 ms. 차이는 연산이 아니라 바이트 수(메모리 대역) |
| 상쇄 `(1e8+0.1234567)−1e8` | f64 상대오차 1.3e-8 · 고정소수 정확 |
| 1e7 작은 델타를 6.02e11 에 누적 | f64 증가분 **~30 % 오차** · 정수(양자 1e-12) 참값과 1e-9(양자 반올림) · 시간 같음 |
| Rust 16.7M 정수 합 | f64 34 ms(**2^53 초과로 틀림**) · i64 14 ms(정확, 순서 무관이라 벡터화) · i128 28–32 ms |
| JS 16.7M 합 | f64 정수 44–56 ms · BigInt64 146–152 ms |

보수 덧셈·비트 시프트를 손으로 쓰는 것은 이득이 없다(CPU 뺄셈이 이미 보수 덧셈). 이득은 **정수 누적의 정확성·순서 무관성**과 Rust 에서의 벡터화다.

## 5. SIMD
- 지금 운명 엔진은 사실상 SIMD 가 없다. WASM 빌드에 `simd128` 이 꺼져 있고, `tape.rs` 는 `match op` 분기 해석기이며, 희소 LU 는 간접 색인이고, 루프 길이는 수십이다.
- T3 칸 배열이 SIMD 자리다. 배열 구조체(종·층별 연속 i64 배열)로 두고, 칸 계산에 분기를 두지 않으며, WASM 에 `-C target-feature=+simd128` 을 켠다.
- 정수 누적은 순서와 무관하므로 벡터화·병렬화 뒤에도 **네이티브 = WASM = 직렬 비트 동일** 규약이 유지된다. 실수 장에서는 이 규약과 SIMD 가 충돌한다.

## 6. 넷째 축 = 물리적 배제 (시간 아님)
- e ∈ {0…k−1} 이산 배제 부류(막 안·막 위·소기관·밀집 구역 …). 칸 (x,y,z,e) 에 들어갈 수 있는지를 기하 자체가 정한다. 지금의 위치 이름·공간 접촉 사후 거부를 기하로 옮기는 것이다.
- 비용 ×k, 대부분 비어 있으므로 희소 저장. **연속 축은 쓰지 않는다**(N⁴ 폭증).
- 부류 정의(어떤 위치가 어떤 e 인가)는 어휘·데이터 층에 둔다. 엔진은 번호만 안다.

## 7. 미분이 남는 곳
- **T2 기전 네트워크**(비선형 효소 사슬·힐 조절)는 지금 Rodas3(+야코비안)를 유지한다. 비선형 강성 반응에는 정확 적분 핵이 없어서, 억지로 적분형으로 바꾸면 덜 정확하다.
- 경계: T2 는 세포·스파크 안의 국소 계산이고, T3 와는 정수 거래로만 만난다. 미분형은 스파크 안에 갇힌다.
- 선형·1차는 T5 정확 핵. 비선형은 국소 선형화 핵을 유효 범위 안에서만 쓰고, 벗어나면 T4 로 넘긴다.

## 10. 열린 질문 (구현 전에 정할 것)
- 분포 변화 지표: 엔트로피 변화율(있음) / 국소 KL / Fano 중 무엇을, 어떤 문턱으로 쓸지 — 보정 데이터가 없으면 Regulatory_Gap 계열로 등록.
- 배제 부류 목록과 위치 어휘의 대응.
- 양자 기본값(분자 수 1 vs 분수 양자)과 블록 축척 갱신 시점(고정 / 범위 넘을 때 재축척 거래).
- T5 열쇠의 매개변수 양자화 — 연속 매개변수는 정확 적중이 드물다. 근처 보간을 허용할지(그러면 P4 처럼 OOD 판정 필수).
- 결정론 exp: 두 백엔드가 같은 소프트웨어 구현을 쓸지, 추첨·문턱 비교를 정수 영역으로 옮길지.

## 11. 해상도 범위 (어림값 — 구현 전, Rust 정수 합 ~10⁹/s·i64 8 B/칸·종 기준)

| 범위 | h | 영역 | 칸 수 | 메모리 (종 10) | 쓰임 |
|---|---|---|---|---|---|
| 조직 | 5–10 µm | 0.5–1 mm | 10⁶–8×10⁶ | 80–640 MB | 케모카인 기울기(수백 µm) |
| 세포 주변 | 0.5–1 µm | 50 µm | ~10⁶ | ~80 MB | 세포가 느끼는 국소 농도·분비·흡수 |
| 막 스파크 (2D) | 20–50 nm | 1–2 µm | 10³–10⁴ | 작음 | 수용체 군집·결합·내재화 |
| < 10 nm | — | — | — | — | 장 불가(분자 크기) → T2 행위자 · R2 구조 |

- 케모카인 1 nM ≈ 5 µm 칸당 75 분자(요동 ~12 %), 1 µm 칸당 < 1 → 본래 저분자수 장. 양자 = 분자 1 이 자연 단위이고 세포 가까이에서 T4(Fano) 가 실제로 켜진다.
- 조직 규모 정확 핵(FFT) 단계당 수백 ms–1 s(네이티브). 전 영역 고해상도(~10¹⁴ 칸)는 불가 — 필요한 곳만.
- 생물 한계(구현 때 반응 또는 Gap 으로): 케모카인의 GAG 결합(고정 기울기)·청소 수용체(ACKR 등) 내재화. 자유 확산만으로는 기울기가 틀린다.

## 12. 맥락 경계 층 (시뮬레이터 밖의 값)

```
맥락 상태(이산·텍스트 수준: 정상 → 염증 → 해소, 전이 시간 분포)
   │ 상태마다 경계 분포 c∞(t) — 값은 관찰 기록(O…)에서
경계선 ∂Ω ─ 바깥: 계산하지 않음(확률 저수조)  /  안: T3 3D 장
   │ 분포 변화·접촉
T4 스파크 · T2 (수용체 → 세포 안 사슬 → 운명 엔진)
```

- **텍스트는 열쇠, 값은 관찰.** 맥락 상태는 어느 관찰 묶음(종·조직·위치·불확도)을 경계 분포로 쓸지 고르는 데에만 쓴다. 관찰이 없으면 `hypothetical: true` + Gap. AI 가 만든 서사는 가설 시나리오의 상태 순서로만 쓰고, 결과는 조건부로 표시된다(사법부).
- 지금의 연결점: 운명 엔진 `signals`(선언된 시각·양) → "맥락 상태 → 경계 분포" 로 넓힌다. 텍스트 층과 수치 층은 경계 하나로만 만난다(층 벽).

## 13. 지식 공백 보고서 (자동 정리)

목적: 무엇을 모르는지(있음)에 더해, **어떤 모름이 목표 달성을 위협하는지**와 **어떻게 닫는지**를 자동으로 낸다. 데이터는 스스로 만들지 못하지만 다음에 무엇을 잴지는 스스로 정한다.

### 13.1 판정 기준 = 목표 달성 + 생존 (세포사가 아님)
- 시나리오에 실행 전 `objective { goal, viability }` 를 선언한다(입력 해시에 들어감, 실행 뒤 변경 금지 — `expect` 와 같은 규약).
  - `goal`: 소기의 목적(예: 표적 상태 도달, 표지 서명 형성, 병원체 제거)과 시간 창.
  - `viability`: 생명체가 유지되는 제약(자원 고갈 없음, 사이토카인 폭주 없음, 표적 외 세포 손실 상한 …).
- 기준값 **J = P(goal ∧ viability)** — 앙상블 위의 확률(적분)이다. 함께 내는 것: 생존 여유(제약 경계까지의 거리 분포).
- 세포 사멸 자체가 목표일 수 있다(감염 세포 제거). 판단은 개체 수준의 `viability` 로 한다.

### 13.2 파이프라인
| 단계 | 내용 | 상태 | 권력 |
|---|---|---|---|
| A 수집 | 한계(8 종)·`--detect` 후보·감사 `fault`·등급 `blocked`·compare Behavior-Changing | 있음 | 사법 |
| B 분류 | **닫는 방법** `measure`(재면 닫힘) · `transfer`(다른 종 값만) · `abstraction`(기전 경계: 접힘·리보솜·크로마틴 — 데이터로 안 닫힘, 속도·확률·자원으로 대체 표현) | 새로 | 사법(규칙) |
| C 영향도 | 모르는 값을 범위 안에서 흔들어 J 의 분산을 매개변수별로 분해(Sobol 지수 — 분산의 적분 분해, 비선형·문턱 결과에 맞음) | 새로 | 조정자(앙상블) → 사법(순위) |
| D 처방 | 상위 공백마다: 무엇을·어느 종/세포에서·어떤 정밀도로 재면 J 가 판정되는가 + 받을 곳(`augment fetch` 대상) | 일부(Observation_Gap 정밀도) | 사법 판결 → 에이전트 수행 |
| E 보고서 | 직전 대비 차이(닫힘·새로·순위 이동), 시간축 | 새로 | 서기 `derived` 구역 |

- 범위: 물리적 상한(`vocab.physicalBounds`) ∩ 같은 계열의 관찰 분포. 범위마다 출처를 붙이고 영향도는 "이 범위 가정 아래" 의 조건부 결과로 표시한다.
- 시점: A·B·E 는 `augment apply`·`fate`·`audit-run` 뒤 자동(정제 점검과 같은 자리), C 는 요청·주기 실행(비용 = 공백 수 × 앙상블, T5 보관으로 반복 조각 재사용).
- 형식: 원본은 JSON 하나. 사람용 렌더는 §13.4 의 논문 형식이다(AI 는 같은 JSON 으로 다음 작업을 고른다).

### 13.3 표현하지 않는 것 (abstraction 경계)과 대체 표현
| 대상 | 대체 표현 |
|---|---|
| 단백질 접힘 기전 | 단계 = 접힘 시간 + 성공 확률 + 샤페론 의존, Structural_Gap |
| 리보솜·전사 기계 기전 | 신장 속도 × 서열 길이, 리보솜 = 유한 저장소(v7), 전사 = 켜짐·꺼짐 폭발 확률(T4 스파크) |
| 크로마틴·후성유전 기억 | 조절 규칙 + Regulatory_Gap (장기 상태 표현은 열린 질문) |
| 세포 이동·형태 | 없음 — 케모카인 장을 넣으면 첫 번째로 필요한 층(열린 질문) |

추가 약점(보고서가 추적): 식별 가능성(여러 상수 조합이 같은 관찰을 맞춤) · 종 간 이전 · 공간 관찰 부족(3D 케모카인 분포 측정이 드묾).

### 13.4 독자 = 논문 · 분야 전문가 (보고서의 최종 목표)
목표는 내부 무결성을 보이는 것이 아니라 **박사급 독자가 인과를 따라가고, 쓰인 값을 믿을 수 있게 하는 것**이다. 무결성 증명(원장·해시·도장)은 본문에 싣지 않고 보충 자료로 내린다. 다만 증명서가 FAIL 인 실행은 지금처럼 결론에 쓰지 않는다(관문은 그대로, 보이는 위치만 바뀜).

| 절 | 내용 | 원천 |
|---|---|---|
| 1 질문 | 목표 J = P(goal ∧ viability), 맥락 상태, 무엇을 보이려는 실행인지(`context.role`) | 시나리오 선언(실행 전) |
| 2 인과 사슬 | 맥락 → 경계 분포 → 국소 농도 → 수용체 → 세포 안 사슬 → 목표 도달, 그림 한 장 + 단계별 근거 | 과정 보고서 §4 인과 추적 확장 |
| 3 값 표 | 값 · 단위(SI) · 불확도 · 종/세포/위치 · **출처(DOI·PMID, 인용)** · 등급 · 관찰 O… | 관찰 기록 `sources`(SCHEMA §근거 — 인용을 지어내지 않음) · `reliability.js` |
| 4 결과 | J 와 구간, 도달 시각 분포, 생존 여유 — 점 추정 하나로 쓰지 않음 | 앙상블 · `stoch_audit` |
| 4′ 검증 | 추정에 쓰지 않은 관찰과의 판정(CONSISTENT · CONFLICT · INDISTINGUISHABLE) · 대안 구조 비교 · 판정 수준 | `obs_compare` · `compare` · §13.5 |
| 5 무엇이 결과를 가르나 | 영향도 상위 매개변수와 그 값의 신뢰도를 나란히 (영향 큼 × 신뢰 낮음 = 결론의 약한 고리) | §13.2 C |
| 6 가정과 한계 | hypothetical 값, abstraction 대체 표현, 종 간 이전, 범위 가정 — 결론이 무엇에 조건부인지 | 한계 · 등급 |
| 보충 | 재현 묶음: 입력 해시, 엔진 판, 시나리오, 무결성 증명서, 표준 내보내기(SBML·SED-ML, 미구현 — 열린 질문) | 과정 보고서 §3·§5 |

신뢰 규칙: 본문 결론에 쓰는 값은 등급 `parameter` 이상만. `bounded` 는 오차 막대와 함께, `hypothetical` 은 표·그림마다 표시한다. 등급 미달 값이 영향도 상위에 있으면 그 사실을 6절이 아니라 **5절 본문**에 적는다(가장 중요한 경고를 부록에 숨기지 않는다).

| P1 | 확률 확산 ~45× | 추첨은 스파크 칸만 | 비용 ≈ (1−f) + 45f (f = 스파크 비율). f 10 % → ~5×, 50 % → ~23×. 세포가 빽빽한 조직(림프절)은 f 가 커서 **조직 규모 확률 장은 ~10⁶ 칸 · 10⁴ 단계 = 분~수십 분**(Rust 어림)이 현실적 상한 |
| P2 | Fano 전역 점화 | 포아송 이탈 기준, 확률 모드 전용, 결정론은 N < N_min | 이탈 판정에 W 단계 창 → **W 단계 지연**, 창보다 짧은 폭발은 놓침 |
| P3 | 케모카인에서 T5 이득 작음 | T5 는 고농도 장, 케모카인은 스파크 경로 | 케모카인 장의 속도는 P1 비용이 상한 |
| P4 | 이동하는 세포가 핵 재사용을 깸 | 조직 규모 = 점 흡수원, 근처 = 스파크 안 실제 모양 | 세포 반경 안 경계층 고갈은 스파크 밖에서 틀림. **부피 분율이 큰 조직**은 점 흡수원이 무효 → 유효 D(굴곡도)가 필요 = Kinetic/Structural_Gap |
| P5 | 스파크 문턱이 숨은 매개변수 | 엄격 문턱 재실행 시 J 수렴 검사(사법) | 비용 ×2–3. **분기점 근처(운명이 갈리는 임계)에서는 수렴하지 않을 수 있음** → 점 예측 대신 분포만 보고 |
| P6 | 추정이 결론 대부분 | 추정 지분을 보고서 5절에 | 해결이 아니라 표시. 지분이 큰 결론은 **가설 생성 수준**(검증 데이터가 들어오기 전까지) |
| P7 | 비선형 반응의 추정 분산 | 추정 표본 K 개를 분기 축에 | 비용 ×K. 확률 1/K 미만의 드문 사건은 분해 불가 |
| P8 | 순차 난수 | 카운터 기반 | **기존 확률 결과와 비트 연속성 단절**(1회, 엔진판으로 구분) |
| P9 | 분기 즉시 발산 | 분기 간 난수 공유 | 분기끼리 상관 → 짝 검정만 유효, 독립 표본 통계 금지 |
| P10 | 분기 폭증·분기 확률 근거 | 상한 + 정확 일치 합치기 | 잘린 분기의 확률 질량만큼 **꼬리 위험 과소평가** → 보고서에 잘린 질량 표시. 맥락 전이 확률은 대부분 가설값 → J 는 조건부 |
| P11 | 초월 함수 잔존 | 전부 정수 구현, FMA 금지 | 구현 비용, exp 위주 코드 ~1–2× 느려질 수 있음, 기존 결과 1회 이동 |
| P12 | JS 오라클 느림 | 작은 격자 대조 | **큰 격자는 Rust 단독**(교차 검증 범위 = 작은 격자) |
| P13 | 캐시 누적·낡음 | 열쇠에 엔진판·IR 해시, 오래된 것 삭제 | 엔진을 바꿀 때마다 찬 시작 |
| P14 | 양자화 vs 민감도 | 표본 뒤 같은 규칙 양자화 | 측정 정밀도보다 작은 민감도는 정의 안 됨(의미도 없음) |
| P15 | 단계 안 왕복 | 단계 ≤ 핵 시간 척도, 트리거 칸만 근 찾기 | 스파크 밖의 **단계보다 빠른 일시 사건**(ms 결합 대 s 장 단계)은 잃음 |

### 15.1 수정 뒤 경계 (할 수 있는 것 / 없는 것)
- **할 수 있다**: 확률 실행의 비트 재현(필연) · 보존 정확 · 물리 요동 / 계산 오차 / 추정 불확도의 분리 표시 · mm 규모 케모카인 장 + 국소 스파크 · 맥락 분기별 J 와 출처.
- **없다**: 빽빽한 조직의 역학·유효 확산의 제1원리 계산 · 1/K 미만·잘린 맥락의 드문 사건 · 분기점 근처의 점 예측 · 스파크 밖의 빠른 일시 사건 · 추정 지분이 큰 결론의 확정 주장 · 기전 수준(§13.3 abstraction).
- 남는 한계는 새 어휘를 만들지 않고 기존 Gap 으로 등록한다: 추정 지분 → Observation_Gap/Concentration_Gap, 유효 D → Kinetic_Gap/Structural_Gap, 맥락 전이 확률 → Observation_Gap.

### 13.5 검증 (객관적 절차 → 신뢰할 수 있는 결론)
절차가 객관적이어도(출처·재현·불확도 분리) 결론이 맞다는 보장은 없다. 모델 구조의 선택, 문헌 값의 조건 차이, 범위·맥락 선택이 남는다. 결론의 신뢰는 **독립 검증을 통과한 범위만큼**이다.

| 검사 | 무엇을 | 장치 | 상태 |
|---|---|---|---|
| V1 독립 관찰 | 추정(`estimation`)에 쓰지 않은 `validation` 관찰을 예측이 맞히는가 — 관찰 연산자로 같은 양을 만들어 판정 | `compiler/obs_operator.js` → `judicial/obs_compare.js` | 있음(관찰 단위) — J 수준 연결은 새로 |
| V2 대안 구조 | 생략·묶음(abstraction, Regulatory_Gap)을 푼 구조와 나란히 돌려 J 가 바뀌는가 — 바뀌면 그 생략이 결론을 좌우한다 | `compare --patch` | 있음 — 보고서 연결은 새로 |
| V3 사전 선언 | `expect`·`objective` 가 실행 전에 입력 해시에 들어 있었는가 | 무결성 증명서 | 있음 |
| V4 외부 재현 | 다른 도구가 같은 반응망으로 같은 결과를 내는가 | SBML 내보내기(결정 8) | 미구현 |

**판정 수준** — 결론마다 하나를 붙이고, 본문 문장의 강도를 이것에 맞춘다.

| 수준 | 조건 | 본문 표현 |
|---|---|---|
| 검증됨 | V1 CONSISTENT ≥ 1 (영향도 상위 관찰량), CONFLICT 0, V2 에서 J 불변, V3 통과 | "예측하며, 독립 관찰 O… 와 일치한다" |
| 부분 검증 | V1 일부 CONSISTENT, 나머지 관찰 없음 또는 INDISTINGUISHABLE | "…와 일치하나 X 는 검증되지 않았다" |
| 미검증 | 검증 관찰 없음 | "모델 예측(가설) — 검증 관찰 필요: 처방 표" |
| 반박됨 | V1 CONFLICT ≥ 1 | 결론으로 쓰지 않는다. 충돌 자체를 결과로 보고하고 DOMAIN_CONFLICT/Observation_Gap 경로로 |

규칙: 추정에 쓴 관찰은 검증에 쓰지 않는다(기존 규약). 검증 관찰이 없다는 사실도 본문 4′ 절에 적는다(빈 절을 생략하지 않는다). 반박된 결과는 숨기지 않는다 — 어느 가정이 틀렸는지가 다음 처방이다.

### 13.7 모의 실험 규약 · 교란 연산자 · 정성 증거
검증은 "실제 실험과 같은 실험을 모델에서 했을 때 같은 결과가 나오나" 이다. 지금은 시나리오가 자유 형식이고, 넉아웃은 시나리오 파일을 통째로 복사해 시작량을 0 으로 둔다(`mhc-i-tap-null` 등). 그래서 대조군과 교란군이 교란 외에도 다를 수 있고, 합성 규칙이 살아 있으면 넉아웃이 아니다.

**모의 실험 규약** (시나리오 형식 확장 — 실행 전 선언 항목은 입력 해시에 포함)
| 항목 | 내용 |
|---|---|
| 질문·가설 | 무엇을 보이려는지(`context.role` 확장) |
| 대응 실험 | 흉내 내는 실제 실험의 출처(DOI)·세포·종·조건·시점 |
| 대조군 | 양성 · 음성(V6) · 기준선 — 음성 대조는 필수 |
| 교란 목록 | 아래 교란 연산자 선언 |
| 측정 | 관찰 연산자로 실제 측정과 같은 읽기 값·시점 |
| 반복 수 | 검정력 계산으로(예상 효과 크기 선언), 임의 지정 금지 |
| 사전 선언 | `expect` · `objective` · `validation: [O…]` · 허용 범위 δ(근거 포함) · 분석 계획 |
| 중단 규칙 | 결과를 보고 반복 수를 바꾸지 않음 |
형식은 SED-ML·MIASE 와 대응되게 둔다(원문 확인 후) — 외부 재현(S1)과 공인 틀(S3)의 바탕.

**교란 연산자** (컴파일러, 순수 — 엔진은 그대로 IR 만 먹는다)
| 교란 | IR 변환 | 필요한 데이터 |
|---|---|---|
| knockout | 시작량 0 + 그 분자를 만드는 합성·공급 규칙 제거 | 없음 |
| block | 규칙 끄기(항체·돌연변이) | 없음 |
| inhibit | 속도 상수 × 1/(1+[I]/Ki) | Ki·용량(없으면 hypothetical) |
| clamp | 농도 고정 | 값 |
| dose_series | 위 교란을 용량 목록으로 반복 | 용량 목록 |
교란 IR 의 해시 = f(기준 IR 해시, 교란 해시). **사법부 교란 차이 검사**: 교란 IR − 기준 IR 이 선언한 교란과 정확히 같아야 한다(그 밖의 차이 0).

**정성 관찰 기록** (db 형식 변경 → 이전 스크립트·SCHEMA): `kind: direction | presence | order | monotone` · 교란 · 읽기 값 · 기대(증가·감소·있음·없음·순서) · 세포·종·조건 · 출처 DOI 와 원문 구절 · `use`. 불변·추정/검증 분리 규칙 그대로.

**정성 판정기** (사법부): 대조군 대비 방향(앙상블 차이 검정), 유무(목표 도달 비율 차이), 순서(시각 분포), 단조성(용량 반응 추세 검정). 카운터 난수(결정 5)가 들어오면 대조·교란이 같은 난수를 공유하는 **짝 판정**(공통 난수)으로 올린다. 판정은 **우연 기준선과 비교**한다 — 방향은 우연히도 50 % 맞으므로 일치 개수를 이항 우연 수준과 대비해 보고한다.

추가 검사(서로 다른 실패 방식 하나당 하나): V5 교란 예측(정성) · V6 음성 대조 · V7 식별 가능성(프로파일 우도) · V8 맥락 이전(조건 A 로 추정, B 를 예측).

### 13.8 이 검증 체계의 한계
| 한계 | 내용 | 대응 |
|---|---|---|
| 보상 작용 | 실제 넉아웃은 유사 유전자·적응·발생 효과로 보상된다. 모델엔 없다 | 불일치를 곧 오류로 보지 않고 L1 원인 분류의 '모델 구조(보상 부재)' 로 |
| 억제제 | 표적 외 효과, 시험관 Ki ≠ 세포 안, 세포 안 농도 모름 | Concentration_Gap, 억제 배율은 대개 hypothetical |
| 정성 증거의 정보량 | 방향 일치는 우연 50 % — 한 건은 거의 증거가 아님 | 우연 기준선 대비, 여러 건 결합 |
| 출판 편향 | "효과 있음" 만 실리는 경향 → 양성 쪽으로 치우친 검증 세트 | 음성 결과 문헌도 찾아 넣고, 세트 구성을 보고서에 표시 |
| 반정량 읽기 값 | 형광 세기·웨스턴 띠는 상대값, 단위 임의 | 관찰 연산자를 상대 변화로, 정성 판정 우선 |
| 종·세포 차이 | 쥐 넉아웃 결과를 사람 세포 모델에 | 맥락 불일치로 표시(V8·L4), 섞지 않음 |
| 문헌 주장 추출 | AI 가 논문 주장을 잘못 읽을 수 있다 | 원문 구절 + DOI 필수, 사람 표본 검토(S1) |
| 공통 난수 | 카운터 난수 전에는 짝 판정 불가 | 그 전엔 독립 검정 + 반복 증가 |
| 음성 대조의 무한성 | 일어나지 않아야 할 일은 무한히 많다 | 선언된 집합에 대해서만 말함 |
| 규약 비용 | 시나리오 작성이 무거워짐 | 기준 시나리오 + 교란 한 줄로 중복 제거가 상쇄 |
| 선언된 δ·효과 크기 | 사전 선언이어도 선택은 주관 | 근거 필수, 보고서에 그대로 |

### 13.9 정성 관찰 그래프 (양방향 · 맥락형)
정성 관찰은 새 저장 구조가 아니라 **이미 있는 번호 그래프(T·D·규칙·묶음·단계) 위에 얹는 주장 간선**이다.
- 간선 하나 = 관찰 기록 O… 하나: (교란 대상 X, 교란 종류) → (읽기 값 Y) · 부호(증가·감소·있음·없음·순서) · 맥락(종·세포·조건·위치) · 출처(DOI + 원문 구절) · `use`.
- **양방향은 색인으로 만든다**(간선은 한 번만 저장): X 에서 "X 를 건드리면 무엇이 바뀌나", Y 에서 "Y 를 조절하는 것은 무엇인가", 맥락 노드에서 "이 세포·조건에서 알려진 인과". 같은 사실을 두 번 적지 않으므로 어긋날 자리가 없다.
- **그래프 대조(시뮬레이션 전 0 층 판정)**: 기전 그래프에서 X → … → Y 경로를 찾고 경로의 부호 곱(활성 +, 억제 −)을 주장의 부호와 비교 — 경로 있음·부호 일치 = 구조 지지, 경로 없음 = Structural_Gap 후보, 부호 반대 = 모순 후보. 엔진을 돌리기 전에 싸게 걸러 내고, 통과한 것만 교란 모의 실험(V5)으로 정량 판정한다.
- 맥락형: 맥락 열쇠(§17)를 노드로 두어 "이 맥락의 주장들" 을 묶어 본다. 다른 맥락의 주장은 섞지 않고 V8(맥락 이전) 대상으로 표시한다.
- 규약은 그대로: 관찰은 불변(철회만), 번호로만 연결, 추정용·검증용 분리.

## 17. 저장 구조 (정의항 20만 이상)

**근거**: `scaling-limits.md` — 단일 db.json 은 정의항 약 20만 개에서 읽기가 실패한다(V8 최대 문자열 537 MB ÷ 정의항당 2.7 KB, 하드웨어와 무관), 힙 약 4.9 GB, 패치 한 건 약 55 s(n^1.3). 목표 규모가 이 벽 위이므로 방아쇠(10만)를 기다리지 않는다. 시뮬레이션 안의 분자 **개수**는 실행 상태라 db 와 무관하다(이 절은 분자 **종류** 기준).

**S1 확인 결과 (2026-10-15, 읽기만)**: 패치 기록 40 건을 빈 db 에서 재생하면 32 건이 오류, 결과 정의항 149 대 현재 211 — **패치 기록만으로는 현재 db 를 재생할 수 없다**(첫 패치 이전의 데이터, v1→v10 이전 스크립트, 번호 재부여). 그래서 기록을 원본으로 바꾸는 시점은 **지금 db 를 기원 체크포인트로 봉인한 그때부터**이고, 이전 패치는 읽기 전용 이력으로 남긴다.
