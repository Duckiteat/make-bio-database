# 작업 검증 · 꼼수 방지 (AI 자기보고를 증거로 인정하지 않기)

> 작업자(AI)가 작업을 생략·조작하고도 완료한 척 보고하는 것을 **탐지·거부**하는 설계. 목적은 성실을
> 기대하는 게 아니라 **불성실한 작업이 통과하기 어렵게** 만드는 것. 요청서(2026-10-17 사용자) + 조사 결론.
> **이 문서는 설계다 — 아직 구현하지 않았다.** 저장소 전체 재설계·규칙 변경은 별도 요청 때.
> 기원: TASK-001(사람 TNF mRNA 반감기) 수집이 대충이었던 일 — 수집가의 "웹 검색함·403" 자기보고를
> 실행 기록과 대조 없이 받아들였다(꼼수 #2·#9). 그 구멍을 닫는 설계.

## 1. 조사 결론 — 지금 무엇이 강제되나 (코드 확인)

| 영역 | 강제? | 근거 |
|---|---|---|
| db 쓰기(종·단위·from·물리상한·why·미등록 한계) | **관문 강제** | `judicial.gate`·`patchPolicy` |
| 정성 관찰 출처: quote 필수 + provenance.source ∈ DOI/PMID | **관문 강제** | `judicial.js:286·288·356` |
| 'verified' = 유효 도장만 | **강제** | `attestation.js` |
| 병합 이력 = 해시 사슬(변조 시 재생 불일치) | **강제** | `clerk.mjs` events.jsonl `{seq,…,prev,root}` |
| 사전 등록 sha(실행 전) | **강제** | `register` |
| 철회 전파 | **됨** | `retractionImpact` |

→ **쓰기 측은 강하게 강제된다. 조사·수집 측은 자기보고를 증거로 인정한다 — 그게 비대칭이자 구멍.**

## 2. 핵심 결론 — 과정이 아니라 결과를 재-도출한다

터미널 검사는 작업자의 **과정**(정말 검색·열람했나, 외부 웹 행동)을 검증 **못 한다**(재생 불가·transcript 소비
불가). 그러나 **결과**(DOI 해석·인용문 원문 대조·값 db 조회·파일·계산·gate·해시 사슬)는 **통합가가 터미널에서
직접 다시 해 결판낼 수 있다.** 그리고 결과 재-도출이 더 강한 보증이다 — **엔진 사법 원리 그대로**(사법부는 엔진
자기보고를 안 믿고 다시 돌려 비트 대조).

> **원칙: 작업자의 과정 정직성을 검증하려 들지 말고, 통합가가 결과를 독립적으로 재-도출하라.**
> 내 재확인이 통과하면 작업자의 과정은 무의미해지고, 실패하면 작업자가 뭐라 보고했든 거부된다.

## 3. 두 레지스터 (보존/비보존 doctrine의 실행 증거판)

| | 결정론·재생 가능(보존類) | 외부·재생 불가(비보존類) |
|---|---|---|
| 예 | 파일 읽기·db 조회·계산 | 웹 검색·원문 fetch |
| 통합가 검사 | **전수 재실행 대조** (싸다) | **표본 재-fetch** + 나머지 **REVIEW_REQUIRED** (비싸다·사람 가능) |
| 자동 보증 | 있음 | 없음 — 진실은 1차 출처/사람 |

## 4. 엔진 기록 형식 재사용 (새 로그 형식 안 지음)

실행 로그를 `clerk` 사건과 **같은 해시 사슬 append-only 형식**으로: 행동마다 `{seq, kind: search|open|read|
extract|calc|error, 입력, 출력해시, prev, root=sha(prev+정준본문)}`. → 꼼수 **#10(사후 변경) 구조적 탐지** +
결과→근거→열람→검색 역추적. **두 조건**:
1. **테이프는 도구 런타임이 쓴다.** 작업자가 자기 테이프를 쓰면 엔진 형식이어도 자기보고로 되돌아간다.
2. **재생 검증은 결정론 행동만.** 외부 행동은 기록만 되고 진실은 통합가/사람.
- **미확인**: harness가 작업자 도구 호출을 구조화 사건으로 내주는가. 내주면 #1·#2·#9까지 강제, 안 내주면 그
  부분은 자기보고+통합가 스팟체크로 두고 **그 한계를 데이터로 등록**(엔진 형식으로 다 막는 척하지 않기).

## 5. 상태 어휘 (기존 재사용)

`identity.js` 판결(`verified·rejected·ambiguous·candidate·missing·unreadable`)·`obs_compare`(INDISTINGUISHABLE)·
`qual_compare`(맞음·틀림·보이지못함·무효)를 요청서 5상태에 매핑: **PASS·INCOMPLETE·BLOCKED·REJECTED·
REVIEW_REQUIRED**. 특히 구별: 조사 안 함 / 검색했으나 없음(missing) / 접근 불가(unreadable·BLOCKED) /
읽었으나 값 없음 / 모호 / 주장-근거 일치 미판정(REVIEW_REQUIRED). **PASS = 자동 조건 충족일 뿐, 과학적 진실·
후속 승인 아님.**

## 6. 못 막는 것 (정직하게 — 숨기면 그게 또 꼼수)

- **#1 커버리지("정말 아무 출처도 없나")**: 없음의 증명 — 작업자 보고로 안 됨. 통합가 재검색(비쌈) 또는 사람(RETRIEVAL_TASKS).
- **#5·#6 내용 진실**(인용이 원문에 있나·출처가 주장과 관련되나): 1차 출처 재-fetch·과학 판단 — 관문 불가, 통합가/사람.
- **외부 웹 행동의 과정**: transcript 소비 불가하면 자기보고+스팟체크.
→ 이들은 **REVIEW_REQUIRED**로 두고 "완료"로 적지 않는다.

## 7. 재사용 · 재실행 기준 (중복 방지)

핸드오프 행에 **출처 id/sha + collected_at + 과제 명세 버전**. 새 과제는 "이미 수집 + 여전히 유효(철회 아님·맥락
일치·버전 동일)"면 **재수집 금지**, 부족분만. **재사용 ≠ 독립 검토 생략** — 재수집 안 해도 통합가 1차 출처 재확인은
필요. 기존 기록 덮어쓰기 금지(새 실행 + 연결, 값 층 `recorded_at`·`moved` 패턴).

## 8. 최소 구현안 (별도 요청 때)

`judicial/collection_audit.js`(신설·읽기 전용) — 핸드오프 + 실행 테이프를 받아:
1. **사슬 무결성**(재생=root) → #10 자동.
2. **결정론 사건 재실행 대조**(파일·db 다시 읽어 주장과 비교) → #2 자동, 싸니 **전수**.
3. **필수 필드·검색경로 선언·"검색/열람/읽음/값있음" 분리** 검사 → #1·#7·#11 (선언 기준).
4. **외부 주장**(DOI·인용)은 통합가 **표본 재-fetch**, 나머지 **REVIEW_REQUIRED**.
5. 완료는 수집가가 아니라 **이 판정기**가 정함.
- 새 방어 규칙 → **거부 픽스처**(§9) + FLOOR 상향. 통과시키려 규칙 완화 금지.

## 9. 실패 테스트 (이름만 추가·기준 완화 금지 — 실제 거부해야)

필드 누락·가짜 DOI(형식)·무효 기존 결과 재사용·자동불가 사안 자동통과(→REVIEW) = **자동 거부**.
가짜 DOI(해석)·인용 불일치 = 통합가 재-fetch 거부(절차). 기록 사후 변경 = 사슬 재생 불일치.
불필요 재조사 = 기존 유효 핸드오프 경고.

## 10. 비용 축 (이 설계의 현실)

가장 싼 길(작업자 로그 신뢰)은 막혀 있다(transcript 소비 불가). 되는 길(통합가 재-도출)은 확실하나 통합가
토큰을 쓴다. **타협: 싼 결정론 재확인 전수 + 비싼 외부 재확인 표본 + 나머지 REVIEW** — 그리고 REVIEW를
완료로 적지 않는다.

## 11. 지문

- **구멍은 조사 측이다.** 쓰기는 이미 못 뚫는데 조사는 자기보고를 증거로 인정했다(TASK-001 표본).
- **고칠 건 과정 검증이 아니라 결과 재-도출.** 엔진 사법 원리를 작업 검증에 그대로. 터미널은 결과를 본다.
- **엔진 형식(해시 사슬·재생)은 재사용하되 경계를 긋는다** — 결정론은 재생 검증, 외부는 기록만. 보존/비보존과
  같은 선. 다 막는 척하지 않고 못 막는 것(#1·#5·#6·과정)을 명시해 사람/통합가로 넘긴다.
