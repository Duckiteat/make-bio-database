> 새 세션은 이 대화를 기억하지 못한다. **이 문서 + 철학 문서들 + CLAUDE.md 를 읽으면 지금의 방향 감각으로 들어온다.** 규율은 `CLAUDE.md`, 원리는 아래 철학 문서들, 플랜·단계 상태는 `build-plan.md`. 이 문서는 "지금 무엇을 왜 그 순서로" 를 잡는다. 2026-10-22 확정.

## 0. 북극성
**현실 검증 — "시뮬레이션이 현실 위에서 기능한다."** 맞는지 틀린지 현실 관찰에 맞춰 검증 가능해야 한다. 그 기계는 6부(42–48): 관찰 연산자(장치 눈먼 곳)·측정 유형 카탈로그·해석해 벤치마크·수렴 스윕·강성 진단·사각 지도. **완성됨.**

## 1. 방향값(최적화 목표) = 자동결정률
새 데이터 중 **사람 없이 기계가 결정(자동 수용 / 근거 있는 자동 거부)하는 비율** 을 비용당 최대화한다. 임계 경제학:
- **임계 아래(지금):** 사실마다 사람·Opus 검증 → 선형·느림·비쌈. (정량 검증 0 — 바탕이 얇다.)
- **임계 위:** 새 데이터를 이미 검증된 코어에 대고 자동 판정 → 초선형. 사람은 잔차(모순·새 축)만.
- **역치 = 데이터 개수가 아니라 교차검사 밀도**(사전·관문·정성 그래프·우연 기준선·보존·커버리지). 검증된 닻·링크가 많을수록 자동결정률이 오른다. 임계를 넘어야 생산성이 나오고, 거기까지가 비용(bootstrap)이다 — 저가 수집가·싼 자동검사·허브 데이터로 그 비용을 줄인다.

## 2. 지배 원칙 — 검증이 능력을 gate 한다
표현력(공간·확률·QSSA)은 그걸 **반박할 관찰·벤치마크와 함께, 또는 그 뒤에만** 온다. 검증가능성을 앞지르는 능력은 48 사각을 새 축에서 재생산한다. 그래서 **4부(적분장)를 stage 1 에서 멈췄다** — 공간 엔진 전에 공간 관찰이 먼저다. "더 큰 엔진" 본능·클린 리라이트는 뒤로.
- 법칙이 있으면 정확(conserved = 산술적 0), 없으면 정직(non_conserved = float + 예산). 4부 stage 1 이 증명(보존 1e-14 근사 → 정확 0).

## 3. 우선순위 귀결 — 지금 무엇부터
1. **데이터 먼저.** 48 이 드러낸 정량 검증 0 을 메운다(TASK-004 류 수집 고리). "현실 위 기능" 의 구속 조건.
2. **공간 관찰(6부의 공간 축 확장)이 공간 엔진(4부 stage 2+)보다 먼저.**
3. **2부는 가독성·검증부터**(12 보고서·16A 사전·13 철회 전파) — 자동결정률을 직접 올림. **저장 규모(15–19)는 db 가 역치(~1만 senses)에 다가갈 때** (효율 스냅샷: 지금 병목은 db 규모가 아니라 Node 부팅, 색인 계층 불필요).
4. 엔진 키우기(4부 후반)는 관문 D + 공간 관찰 뒤.
5. **2026-10-23 — 7부 구조 재편**(`structure-realignment.md`): 가정·판정·측정법을 1급 기록으로 세우고, 그 위에 입력 귀속을 올린다. 결론이 실측에 매였는지를 재는 일이라 위 1(데이터 먼저)과 나란히 간다.

## 4. 형태 결정 — 왜 하나로, 어떻게 병렬
- **한 순수 엔진 코어 + 하나의 불변 db.** 통합해야 "검증되는 것 = 키우는 것" 이라 오차 수렴이 의미를 가진다. 엔진을 포크하면 두 코드 경로가 생겨 비교·수렴이 깨진다.
- **seam 은 코드가 아니라 사실의 지위**(`use` validation/estimation · `hypothetical` · 신뢰 등급 · 커버리지). 검증된 코어 ↔ 탐색 변경을 데이터로 가른다 — 두 시스템으로 쪼개지 않는다.
- **병렬**: 실행 병렬 = 순수성 + 불변 db 를 fan-out(probe_pool·ensemble); 작업 병렬 = 역할 분리(수집가/통합가). 쓰기(패치)만 관문에서 직렬.
- **특화 = 한 코어 위의 플러그 모듈**(관찰 kind·교란 연산자·기하 부류), 별도 엔진이 아니다.

## 5. 자동화 트라젝토리 (MCP)
collect→verify→patch 고리를 MCP 도구로 자율화한다. 쓰기는 관문이라는 직렬 검증점을 지난다(자동날조 방지 — 검증 척추가 자동화를 안전하게 만든다). **사람은 frontier(새 모순·새 축·"이 모순이 뭘 뜻하나"), 기계는 routine(기형·모순·중복·범위밖).** 한계비용 → 작게, 0 은 아님. 자동화는 도메인별로(교차검사 밀도가 densify 되는 순서) 켜진다.

- **2026-10-23**: 외주화 경계와 MCP 분리(수집 쪽 먼저) — `outsourcing-and-mcp.md`. 원칙: 만드는 일은 외주화, 판정·쓰기는 안에.

## 6. 오차 수렴의 경계 — 과대약속 금지
오차는 **측정이 닿는 데까지, 데이터가 있는 양에 대해서만** 수렴한다. 48 사각(정량 검증 0)인 양은 수렴이 아니라 정직한 공백이다. 커버리지 지도가 그 프런티어를 보여준다.
