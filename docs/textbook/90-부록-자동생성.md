| 구역 | 뜻 | 분류 | 덮어쓴 파일 |

| ore | 원료 — 넣는 것: 지식 정본(db.json)·관찰 기록·외부 원본 사본. 관문을 지나야 들어온다 | `source` · `evidence` | — |
| furnace | 노 — 돌리는 것: 법(코드)·엔진·컴파일러·도구·시험·시험용 장입물(가상 시나리오) | `law` · `interface` · `verification` · `scenario` · `config` | — |

### 원천 데이터 (`source` · 구역 ore)

### 증명 등록부 (사법부 도장) (`attestation` · 구역 product)

'verified' 의 유일한 근거. 사법부(judicial/attestation.js)가 발급한 도장을 입법 서기만 기록한다. 도장마다 digest·증거 파일 sha256·같은 확인 재실행으로 검증되며, 데이터는 스스로 verified 를 선언할 수 없다. 손으로 고치면 digest 가 깨져 무효가 된다.

| 경로 | 형식 | 쓰는 쪽 | 읽는 쪽 | 해석 |
|---|---|---|---|---|
| `attestations/registry.json` | JSON {format: definition-db-attestations, version, stamps[]} | 입법 서기만 (appendAttestations — 사법부 도장, 재검증 뒤) | judicial/attestation.js validStamps → validate(db, { attestations }) | 도장: subject(정의항·필드·종류:값) · claim verified · evidence(수신함 파일·sha256) · issuer(모듈·코드 sha256) · issued_at · digest. validate 는 status verified 마다 유효한 도장을 요구한다. |

| T2 | 구성 요소 화학량 | → R1 · 결합체 형성·해리·분해 — 구성 요소 개수가 결과를 정할 때 |
| T3 | 경쟁 | → R2 · 같은 묶음을 두 단계 이상이 소비할 때. 속도 상수(Kd·kcat·Km)가 있으면 R1 에서 해결되고, 없으면 반응 중심 구조가 필요하다 |
| down | 하향 전환 (반응 중심 → 풀) | 사건이 끝나 산물이 풀로 돌아갈 때 — 바뀐 부위는 묶음 키의 부위:특징으로 남고(무손실), 수송·해리는 특징 보존을 검사받는다 |

## 9.7 명령 (dbtool.mjs 머리 주석)

```
  node dbtool.mjs status                                  저장소 요약
  node dbtool.mjs validate                                전체 검사 (오류 있으면 종료 코드 1)

                                                          병합 + Patch Report(Scope·Why·Impact·Verification). patch.why 필수, 미등록 한계 후보가 있으면 거부
                                                          매핑 → 검사 → 관문 통과 시 저장, 적용한 패치는 data/patches/ 에 기록
  node dbtool.mjs map       <번호|이름|이름#n|외부ID|지문>   참조가 어느 정의항(D…)으로 매핑되는지
  node dbtool.mjs audit                                   매핑·채움 현황 (외부 ID 대조 여부, 미매핑, 잔기 모름, 구조 지문)

  node dbtool.mjs mechanism <S…|경로 번호·이름> [--up N] [--down N]

  node dbtool.mjs pattern   <경로|상위 개념>              경로에서 상위 패턴(모티프) 찾기, 또는 상위 개념이 나타나는 경로

  node dbtool.mjs textbook  [--write | --check]            교과서 부록(docs/textbook/90-부록-자동생성.md) 생성 / 최신·파일 분류 검사
  node dbtool.mjs simulate  <경로> --rate [--scenario s.json] [--t 60] [--dt 0.001] [--reservoirs finite|infinite] [--stochastic] [--seed N] [--until-death] [--window s] [--death-frac f]
```
