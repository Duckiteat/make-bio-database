## 다른 문서와의 관계

- **[`docs/PROMPTS.md`](../PROMPTS.md)** — *무엇을 맡기나*(프롬프트 묶음). 작업 종류별 프롬프트와 제작 가이드, 다른 AI 를 함께 쓸 때의 경계.
- **[`docs/RUNBOOK.md`](../RUNBOOK.md)** — *무엇을 치나*(실행 설명서). 돌릴 수 있는 것, 확인된 상태×시나리오 짝, 결과를 읽는 법, 하면 안 되는 것, 관문 거부 → 고칠 곳. **작업을 시작할 때 이 파일 하나만 읽으면 된다** — 교과서는 막혔을 때 가리킨다.

- **`SCHEMA.md`** — *무엇이 허용되나*(필드·규칙의 명세, 형식 변경 기록). 교과서는 *왜·어떻게 돌아가나*.
- **`CLAUDE.md`** — 에이전트가 세션마다 지킬 규칙의 한 줄 점검표(해설판 `docs/design/agent-rules.md`). 교과서 7장이 그 절차를 풀어 쓴다.
- **`limitations.md`** — 지금 모델이 못 하는 것(생성물). 8장이 그 구조와 쓰임을 설명한다.
- **`docs/design/scaling-limits.md`** — 규모가 커지면 어디가 먼저 터지는지 **측정한** 기록과, 그 한계가 구조인지 하드웨어인지의 판정. 쪼개기·로더를 설계하기 전에 먼저 읽는다.
- 코드와 문서가 어긋나면 **코드(`core.js`·`vocab.js`)가 맞다**. 교과서를 고친다.

## 교과서를 관리하는 규칙

1. 지금 값(어휘, 통계, 명령, 저장 지도 표)은 **손으로 쓰지 않는다** — `node dbtool.mjs textbook --write` 가 9장을 만든다.
2. 파일을 더하거나 옮기면 [`storage-map.json`](storage-map.json) 에 분류를 적는다. 분류되지 않은 파일이 있으면 `textbook --check` 가 실패한다(CI).
3. 알고리즘·형식을 바꾸면 해당 장(4·3·5·6)을 같은 커밋에서 고친다. 함수 이름은 `core.js` 의 실제 이름을 쓴다.

## 30초 요약 (AI 용)

```
지식 = data/db.json (T 개념 · D 정의항 · S 단계 · L 한계). 직접 편집 금지 — 패치 → node dbtool.mjs merge.
규칙 = vocab.js(어휘) + core.js(검사·계산). 정의항(D)이 구조·규칙을 소유하고, 단계(S)는 규칙 참조 + 묶음 키만.
묶음 키 D…|부위:특징|위치 · 상태·사례·한계 상태는 저장하지 않고 계산한다.
확인 못 한 값(ID·잔기·속도 상수·인용)은 지어내지 않는다 → unmapped / residue_unknown / 한계 등록.
값마다 등급이 **계산**된다 (저장하지 않음): S 출처 × D 성질 + 추세(지금도 합의와 같은가) → anchor·parameter·bounded·legacy·reference·blocked.
  시뮬레이션은 쓰는 자리에서 등급을 강제받고(문턱 기본 parameter), 시나리오가 준 가상 상수는 hypothetical 선언 아래에서만.
파일 쓰기는 입법 서기 하나, 그 안에서 **구역**이 쓸 자리를 가른다 — 봉인이 유효해도 구역 밖이면 거부.
작업 순서: status → map → (patch) validate → merge → limitations --write → pattern·resolution → audit-run → attest·trend·grade → textbook --write → 테스트.
```
