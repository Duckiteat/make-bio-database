# 첫 사전 등록 현실 검증 — β2-마이크로글로불린 결손이 표면 펩타이드–MHC I 을 줄이는가 (TIER A, 2026-10-16)

> 이 저장소에서 **처음으로 사전 등록된 규약 아래 결론급으로 돌린 검증**이다. 앞선 MHC I 묶음 보고서
> (`2026-10-15-mhc1-qualitative-batch.md`)는 같은 관찰 O000021 을 **탐색 실행**으로만 둘 수 있었다 —
> 규약을 세우지 못했기 때문. 오늘 달라진 것: O000021 의 측정 세포(Daudi)가 관찰 note 에 적혀 있어
> `matched_experiment.system.cell` 을 정직하게 채울 수 있었고, 그래서 규약을 선언·사전 등록·실행했다.

## 0. 한눈에

| 칸 | 내용 |
|---|---|
| **질문** | β2-마이크로글로불린을 없애면 세포 표면의 펩타이드–MHC I 복합체 양이 줄어드는가 — 모델이 β2m 결손 실험(Seong 1988, Daudi)의 **방향**을 재현하는가? |
| **결론** | **맞음 (감소)** — 사전 등록 검증 세트의 결론. 교란군에서 표면 펩타이드–MHC I 이 −22,880 분자. |
| **판정 수준** | 결론(사전 등록 #1). 단 **통계적으로 유의하지 않음**: 우연 확률 0.147 > α 0.05. 그리고 상수가 가상이라 **방향** 재현이지 크기 예측이 아니다. |
| **얻은 것** | ① 사전 등록 → 실행 → 판정 파이프라인이 end-to-end 로 돈다. ② 기전이 **방향을 재현**하고 **음성 대조를 구별**한다. |
| **바닥의 불안정함** | 단일 데이터 1건(우연과 못 가름) · Daudi → 수지상 세포 맥락 이전(L000111) · 가상 상수. |

## 1. 무엇을 물었나

실제 실험은 **Seong et al., 1988, J Exp Med** (PMID 3279151 · DOI 10.1084/jem.167.2.288):
β2-마이크로글로불린이 없는 사람 버킷림프종 B 세포주 **Daudi** 는 표면 class I 이 없고,
β2m 유전자를 넣어 복원하면 표면 class I 이 돌아온다. 정성 관찰 **O000021** 이 이것을
교란 대비 방향으로 적는다: **β2m 녹아웃 → 표면 펩타이드–MHC I 감소** (기대 `decrease`, 종 9606).

검증이 묻는 것은 하나다 — **같은 교란을 모델에서 걸면 같은 방향이 나오는가.**
크기가 맞는지는 묻지 않는다(상수가 가상이므로). 방향만 묻는다.

## 2. 인과 사슬 — 왜 줄어야 하는가 (이름으로)

```
β2-마이크로글로불린 (제거)
      │  없으면 중쇄가 짝을 못 찾는다
      ▼
빈 MHC I (중쇄–β2m)  ──✗ 조립 안 됨
      │  (조립 단계는 β2m 을 입력으로 받는다)
      ▼
펩타이드–MHC I 복합체  ── 생성 급감
      │  소포체 이탈 → 골지 → 세포막 전달
      ▼
세포 표면의 펩타이드–MHC I  ── 감소 ●(실측 방향)
```

- 부호 계산: 교란은 **제거(−)**, 그 분자는 복합체 생성의 **필수 입력(×)**, 생성은 표면량에 **양(+)** 으로
  기여 → `− × + = 감소`. 반대 부호 경로 없음(0 층 구조 판정 `qualgraph` 가 걸러낸 것과 같은 논리).
- 이것은 상시(housekeeping) 생물학이다: β2m 이 표면 MHC I 에 필요하다는 것은 모든 유핵 세포에 공통.
  그래서 **측정 세포(Daudi)와 모델 상태(수지상 세포)가 달라도 이 특정 읽을거리의 이전 위험은 낮다** —
  낮을 뿐, 0 은 아니다(§5).

## 3. 데이터 — 전부 (성공·음성 대조·우연)

### 3a. 본 판정 (교란군 대 대조군)
| 항목 | 값 | 뜻 |
|---|---|---|
| 대조군 | `mhc-i-b2m-validation-hypothetical.json` (상태 미성숙 수지상 세포) | 교란 없음 — baseline 을 인라인 복사한 자기완결 시나리오 |
| 교란 | 관찰 O000021 이 선언: β2m 녹아웃 | 교란은 시나리오가 아니라 **관찰**이 선언하고 `observeQualitative` 가 적용 |
| 표면 펩타이드–MHC I 차이 | **−22,880 분자** | 교란군이 대조군보다 낮음 → 방향 `decrease` |
| 분해능 | 1.00 (수치 오차 + 분자 1개 양자) | 차이(2.3만)가 분해능(1)보다 훨씬 커 **구별됨** |
| 결과 | **맞음 (decrease)** | 기대 방향과 일치 |

### 3b. 음성 대조 — 모델이 늘 "감소"를 외치지 않음을 확인
| 항목 | 값 | 뜻 |
|---|---|---|
| 교란 | HLA-DM 녹아웃 (MHC II 전용 분자) | 표면 펩타이드–MHC **I** 과 무관한 경로 |
| 표면 펩타이드–MHC I 차이 | **+1.6e-9 ≈ 0** | 변화 없음 |
| 결과 | **no_change (= 옳게 "틀림")** | 기대를 `decrease` 로 넣어도 모델은 감소를 **안** 보고함 |

→ 기전이 **교란 종류를 구별한다**. β2m 은 줄이고, 무관한 HLA-DM 은 안 줄인다.

### 3c. 우연 기준선 — 맞힌 것이 우연 이상인가
| 항목 | 값 | 뜻 |
|---|---|---|
| 같은 실행의 다른 읽을거리 | 34 개 | β2m 교란에서 측정 가능한 다른 묶음들 |
| 그 중 같은 방향(감소)이 나온 비율 | **0.147** (≈ 5/34) | 경험적 영 가설 (결과 칸 균등 가정이면 0.333) |
| 판정 1건 중 맞음 1건, 우연으로 1건 이상 맞힐 확률 | **0.147** | α 0.05 **위** |

**정직한 읽기: 단일 정성 일치는 그 자체로 우연과 구별되지 않는다(p 0.147 > 0.05).**
결론은 "방향 재현 + 파이프라인 작동"이지 "유의한 검증"이 아니다.

## 4. 검증 기준과 그 근거 (무슨 기준으로 "결론"이라 부르는가)

판정이 **탐색 실행**이 아니라 **결론**이 되려면, 실행 **전에** 다음을 선언하고 사전 등록해야 한다
(`judicial/protocol.js` — build-plan 3). 각 칸이 왜 있는지:

| 규약 요건 | 이번 값 | 왜 이 기준인가 |
|---|---|---|
| `question` | §0 의 질문 | 무엇을 보이려는지 실행 전에 못 박아, 결과를 보고 질문을 바꾸지 못하게 |
| `matched_experiment.source` | PMID 3279151 (Seong 1988) | 흉내 내는 **실제 실험**의 출처 — 지어낸 기대가 아님을 보증 |
| `.system {species, cell, condition}` | 9606 · Daudi · 복원 전후 유세포분석 | 어느 계에서 잰 것인지 — 셋 다 있어야 통과(세포가 비면 거부) |
| `.readout_times_s` | [43200] | 실제 측정 시점(정상 상태 12h) |
| `controls.negative` | HLA-DM 녹아웃은 안 줄어야 함 | **음성 대조 필수** — 늘 "감소"로 나오는 기계를 걸러냄(§3b 로 실제 확인) |
| `validation` 세트 | [O000021] | use=validation · 철회 아님 · **어떤 상수의 근거(from)로도 안 쓰임** → 추정·검증 분리(순환 금지) |
| `replicates` / `stopping.fixed_n` | n=1 / true | 결정론 실행은 1회 · 결과를 보고 반복 수를 바꾸지 않음 |
| 사전 등록 | #1, 2026-10-16T14:58:50Z, sha256 `62b809ca48b0…` | 시나리오 정준 해시가 등록부 사슬에 있고 등록 시각이 실행보다 **앞섬**. 등록 뒤 한 글자만 고쳐도 해시가 달라져 미등록 |
| 유의 문턱 α | 0.05 | 우연으로 맞힐 확률이 이보다 커야 "우연과 못 가름" (이번엔 0.147 > 0.05 → 못 가름) |

왜 **정성(방향)** 검증인가 — 모델의 상수가 가상(hypothetical)이라 크기는 측정 예측이 아니다.
방향(늘다/줄다/안 변하다)은 상수 크기에 둔감한 기전의 귀결이라, 가상 상수 위에서도 반증 가능하다.
왜 **추정·검증 분리**인가 — 어떤 상수를 맞추는 데 쓴 데이터로 그 모델을 검증하면 순환이다.
그래서 정량 관찰 22건(전부 use=estimation)은 이 검증에 못 쓰고, use=validation 인 정성 관찰만 쓴다.

## 5. 실패·막힌 것·바닥의 불안정함 (숨기지 않음)

1. **단일 데이터 1건 — 우연과 못 가름.** p 0.147 > α 0.05. 한 건으로는 통계적 힘이 없다.
   같은 적재 경로의 다른 결손(TAP·타파신·HLA-DM)을 각각 규약으로 올려 검증 세트를 넓혀야 p 가 내려간다.
   **주의**: 세 MHC-I 교란(β2m·TAP·타파신)은 **같은 하류**(적재 → 표면)를 공유해 완전히 독립이 아니다 —
   우연 기준선을 단단히 하려면 하류가 **다른** 관찰이 필요하다(교차제시·ERAP 등).
2. **맥락 이전(V8) — L000111.** 실제 실험은 Daudi(B 세포)에서 쟀는데 모델엔 수지상 세포 상태만 있다.
   이 읽을거리에선 이전 위험이 낮지만(상시 생물학, §2), 전제로 남아 데이터로 등록했다.
3. **가상 상수.** 방향은 믿을 수 있으나 크기(−22,880)는 기전의 귀결이지 측정 예측이 아니다.
4. **TAP(O000019)는 여전히 막혀 있다 — L000107.** 초록만 받아 측정 세포를 몰라 규약의 세포 칸을 못 채운다.
   O000021 을 올릴 수 있었던 유일한 이유는 Daudi 가 note 에 적혀 있었다는 것뿐이다.

## 6. 지문 (이 검증의 사고 패턴)

- **실행 전에 못 박는다.** 질문·실제 실험·음성 대조·중단 규칙을 사전 등록하고, 해시로 잠근다.
  결과를 보고 사후에 기준을 바꿀 길을 구조로 막았다.
- **추정과 검증을 섞지 않는다.** 모델을 맞추는 데 쓴 값으로 그 모델을 검증하지 않는다.
- **맞힌 것을 우연과 잰다.** 같은 실행의 다른 읽을거리로 경험적 영 가설을 세워, "그럴듯함"을 "우연 이상"과 가른다.
- **완벽을 의심한다.** 음성 대조가 없으면 "늘 감소"하는 기계도 100% 맞힌다 — 그래서 음성 대조를 **실제로** 돌려 확인했다.
- **실패를 데이터로 남긴다.** 막힌 것(L000107), 전제(L000111)를 산문이 아니라 한계 레지스트리에 등록한다.

## 7. 얻은 것 · 다음으로 나간 지점 · 바닥

- **얻은 것:** 저장소 최초의 **결론급 사전 등록 검증**. 신뢰 기층(사전 등록·추정/검증 분리·음성 대조·우연 기준선)이
  말이 아니라 **돌아가는 파이프라인**임을 한 건으로 증명했다. 기전이 방향을 재현하고 교란을 구별한다.
- **다음으로 나간 지점:** 이제 "검증 한 건"이 "검증 세트"로 쌓이는 길이 열렸다. 같은 틀로 O000020(타파신)·
  O000022(HLA-DM II)을 각각 규약으로 올리면 합친 우연 확률이 α 아래로 내려간다. 이것이 **첫 신뢰 닻**이다.
- **바닥(어디가 불안정한가):** 통계적 힘(1건) · 맥락(세포 상태 1종) · 크기(가상 상수). 셋 다 "자원이 먼저"라는
  원칙이 가리키는 그 자원 — 더 많은 검증 관찰, 더 많은 세포 상태, 실측 상수 — 를 모으면 올라간다.
