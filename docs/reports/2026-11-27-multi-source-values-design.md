## 0. 한 줄

값 층의 열쇠마다 **현재 값 하나** 라는 규칙은 그대로 둔다. 그 하나를 **여러 관찰에서 정해진 계산으로 만든 값**으로 만들 수 있게 유도 방식 `pooled` 하나와 독립 단위 계산을 더한다. 형식 번호는 v12 그대로(하위 호환 선택 칸), 엔진은 바꾸지 않는다. 만드는 시점은 **같은 열쇠에 독립 출처가 둘인 첫 사례가 생길 때**다 (RULE-0462).

## 2. 원칙 [제안]

| 범위 | 이유 | 영향 | 확인 |
|---|---|---|---|
| ① 관찰은 출처마다 따로 | 관찰(O…)은 이미 측정 하나 = 기록 하나 | 형식 변경 없음 — 다중 출처의 원자료는 관찰 층에 쌓임 | 형식 v10 |
| ② 현재 값은 열쇠마다 하나 | 엔진 · 컴파일러 · 사법부가 이 가정 위에 있음. 깨면 모든 소비자가 바뀜 | RULE-0233 그대로 | `currentValues` 사용처 |
| ③ 합친 값은 **재계산 가능**해야 | 관문이 `from` 의 관찰들로 같은 계산을 다시 해서 같은 숫자가 나와야 통과 (결정론) | 누가 합쳐도 같은 답 — 숨은 판단이 없음 | 기존 `kinetics.from` 대조 (RULE-0084) 와 같은 방식 |
| ④ 같지 않은 것은 합치지 않음 | 종 · 위치 · 기질 · 온도 · pH 가 다른 관찰은 다른 열쇠 | 합칠 수 있는지는 열쇠가 정함 — 사람이 고르지 않음 | 형식 v12 §5 맥락 열쇠 |
| ⑤ 같은 논문은 한 표 | 한 논문의 조건 변형 여러 개가 독립 측정 여럿으로 세지면 근거가 부풀려짐 | 독립 단위 = 논문 (§3.2) | 11-03 보고서 §2.3 |
| ⑥ 벌어짐은 숨기지 않음 | 출처끼리 크게 다르면 평균 하나로 덮지 않고 한계 후보로 알림 | 자동으로 데이터를 고치지 않음 — 알리기만 | RULE-0039 · 한계 Consensus_Gap |

## 3. 형식 [제안]

### 3.1 유도 방식 `pooled`

```json
{
  "subject": "D000149/rule/condense",
  "property": "Km",
  "substrate": "D000…",
  "context": { "species": "9606", "location": "mito_matrix" },
  "value": { "dist": "lognormal", "mean": 5.2e-6, "sd": 0.38 },
  "from": ["O000024", "O0000xx"],
  "derivation": "pooled",
  "pool": { "method": "log_median", "units": [["O000024"], ["O0000xx"]] },
  "supersedes": "V000066"
}
```

| 범위 | 이유 | 영향 | 확인 |
|---|---|---|---|
| `derivation: "pooled"` | 여러 관찰을 정해진 방법으로 합친 값이라는 표시 | DERIVATIONS 에 하나 더함 · `from` 2 개 이상 필수 | 시험: from 1 개면 거부 |
| `pool.method` | 합치는 방법을 이름으로 — 처음에는 하나만 (§7 Q1) | 다른 방법은 소비자가 생길 때 더함 (RULE-0462) | 어휘 `vocab.poolMethods` |
| `pool.units` | 독립 단위별로 묶은 관찰 목록. 같은 논문 관찰은 한 묶음 | 관문이 §3.2 계산과 같은지 대조 — 손으로 묶음을 꾸밀 수 없음 | 시험: 같은 PMID 를 두 묶음으로 나누면 거부 |
| `value` 다시 계산 | 관문이 `from` 관찰의 값 · 단위 · 불확도로 `method` 를 다시 돌려 `mean` · `sd` 가 같은지 봄 (상대 오차 허용 값 1 개) | 합친 숫자를 지어낼 수 없음 | 기존 RULE-0084 대조 방식 |
| `from` 관찰의 열쇠 | 모든 관찰이 값과 같은 대상 · 속성 · 기질 · 맥락이어야 | ④ 원칙의 집행 | 시험: 다른 종 관찰을 섞으면 거부 |
| 기존 값 | 손대지 않음 — 새 `pooled` 값이 `supersedes` 로 대체 | 이관 스크립트 없음 · 형식 번호 v12 그대로 | 기질 축(11-03)과 같은 방식 |

### 3.2 독립 단위 (저장하지 않고 계산)

| 범위 | 이유 | 영향 | 확인 |
|---|---|---|---|
| 단위 열쇠 = 관찰의 출처 논문 | `evidence.sources` 의 PMID → 없으면 DOI → 없으면 관찰 번호 자신 | 같은 논문의 관찰은 하나로 셈 | 순수 함수 `independenceUnits(db, obsIds)` |
| 같은 연구실의 다른 논문 | 처음에는 다른 단위로 셈 (보수적이지 않음 — 한계로 등록) | 저자 대조는 뒤로 미룸 | §7 Q2 |
| 쓰는 곳 | `pool.units` 대조 · 신뢰 기준 표의 `independence` 요구 (지금 늘 미달인 I 축) | build-plan 52 · 71 의 I 축 입력이 됨 | `reliability.js:276` |

## 5. 위험과 반론

| 범위 | 이유 | 영향 | 확인 |
|---|---|---|---|
| 다른 측정법을 섞음 | 열쇠가 같아도 측정 방식(받개 · 완충액)이 다르면 값이 다름 — 조건 칸이 아직 좁음 (11-03 보고서 §2.2) | 합친 값이 서로 다른 양의 평균일 수 있음 | 측정 조건 칸 확장이 먼저이거나, `pool` 에 측정법(assay) 일치 검사를 더함 |
