## 5. 5개 모드 전부에 쓸지

"쓸지"는 두 층으로 나눈다. **표 · 열쇠 · 연결 장부 · 탐침 · 구조 검사**는 저장소 전체(모든 모드)에 이미 적용된다. **L6 보호(사람의 커밋으로만)** 는 모드마다 `modes.json` 의 쓰기 목록으로 걸리므로 모드별로 다르다.

실측(`mayWrite`, 이름 하나로 적힌 자리 — L6 18 · L5 7 · L4 3 · L3 7 중 쓸 수 있는 수):

| 범위 | 이유 | 영향 | 확인 |
|---|---|---|---|
| **develop** — L6 8/18 → except 로 막은 뒤 **0**(권한의 뿌리 7 + 문지기 셋 막음). 남은 L6 쓰기: 자기 검사 시험 8(ask) | 이 세션이 쓰는 모드 | 완료. Bash 로 시험 8 을 고치면 ask 를 우회(약점 #2) | 실측 |
| **field** — 쓰기 목록 `tests/**` · `docs/**` 가 L6 **12 파일**에 닿음(자기 검사 시험 8 + 권한의 뿌리 시험 3 + `authority.json`) | 방금 보호한 권한 표와 판정 시험이 field 에서는 열려 있다 | **구멍.** 묶음 2 의 보호가 field 에는 없다 | 실측 |
| **author** — L6 0 · L5 7/7(`data/**`) | L5 는 쓰기 목록이 열어 두고 서기 · 사법부 열쇠(도구)로 지킨다 | L6 는 안전. L5 직접 편집(Edit/Write)은 설정 deny 가 일부만 막음(`assays` · `assumptions` · `dictionary` 는 deny 밖) — 봉인 사슬이 사후에 잡음 | 실측 · settings deny |
| **baseline** — L6 0 · L5 2/7(`assumptions` · `preregistrations`) | 같은 구조 | L6 안전. L5 직접 편집 갭은 author 와 같음 | 실측 |
| **inspect** — L6 0 · L5 1/7(`attestations`) | 도장은 사법부 열쇠, settings deny 가 손 편집 차단 | 안전 | 실측 |
| **수집가(author/collector)** — L6 0 · L5 0 · 쓰기는 handoff 뿐 | 역할이 좁음 | 안전 | 실측 |

| 범위 | 이유 | 영향 | 확인 |
