## 0. 한 줄

신호의 종류는 많아 보이지만, 엔진이 새로 갖춰야 할 것은 **축 넷**으로 줄어든다: ① 시간 모양 ② 공간 ③ 세포와 세포 사이 ④ 전하(막 전위). 지금은 그중 시간(계단 모양)만 있다. 시냅스는 넷이 모두 필요한 **합성 신호**라 마지막에 온다. 엔진은 분자 이름을 모르는 일반 장치로만 넓힌다 (RULE-0009 · RULE-0471).

## 2. 신호의 형태 — 무엇이 필요한가

| 형태 | 예 | 엔진이 알아야 할 것 | 지금 |
|---|---|---|---|
| A 고른 농도 | 혈중 호르몬(에피네프린), 세포 안 2차 전령(cAMP) | 구획의 양 | **있음** |
| B 시간 모양 | Ca²⁺ 진동 · NF-κB 진동 · 펄스 길이 · **빈도** 부호화 | 주기 · 펄스열 입력, 빈도를 읽는 하류 | 계단 · 펄스만 (주기 입력 · 빈도 해독 없음) |
| C 공간 기울기 | 케모카인 국소 고농도 · 형태 형성 물질 | 근원 위치 · 확산 계수 · 분해 · 세포의 위치 | 없음 (T3 설계) |
| C′ 표면에 붙은 기울기 | 림프관 · 혈관 내피의 GAG 에 붙은 CCL21 — 떠다니지 않음 | 결합 상태 · 2D 면 위 분포 | 없음 |
| C″ 기울기를 지우는 쪽 | 비전형 수용체(ACKR)가 삼켜 기울기를 만듦 | 소모 규칙 + 공간 | 소모 규칙은 있음 · 공간 없음 |
| D 접촉 | Notch–Delta · TCR–MHC 면역 시냅스 | 두 세포 · 맞닿은 면 | 없음 |
| E 전기 | 막 전위 · 활동 전위 · 간극 연접(전기 시냅스) | 전하 보존 · 막 용량 · 통로 전도도 · 네른스트 전위 · 막 면적 | 없음 |
| F 화학 시냅스 | 전기 → Ca²⁺ → 소포 방출(양자적 · 확률적) → 20 nm 틈의 전달 물질 → 수용체 → 전류 | E + 아주 작은 구획 + 확률 방출 + 두 세포 | 없음 — **E · C · D · 확률 층의 합성** |
| G 기계 · 물리 | 전단력 · 늘림(Piezo) · 빛 · 온도 | 힘 · 변형 | 범위 밖 (`integral-field-engine.md` §13.3 "형태 · 역학은 표현하지 않음") |

## 6. 실험 하나 고르기 — 후보 [결정 필요]

| 후보 | 지금 db 와 이어짐 | 필요한 축 | 맞대 볼 관찰 |
|---|---|---|---|
| 수지상 세포가 성숙하면 CCR7 이 생겨 림프관 쪽 CCL21 을 따라감 | 성숙 · 미성숙 수지상 세포 상태가 이미 있음 (MHC 경로) | ①(없어도 됨) · ②′ → ② · C′(GAG 결합) | CCR7 결손 · CCL21 결손 이주 실험 (정성 — 관문 A′ 방식) |
| LPS 뒤 NF-κB 핵 이동 진동 | LPS → TLR4 → NF-κB 경로가 있음 · L000006(시간 없음) | ① · 속도 상수 | 단일 세포 영상의 진동 주기 (정량) |
| 활동 전위 한 번 | db 에 신경 정의항 0 — 처음부터 | ④ · 이온 · 막 면적 | 고전 전압 고정 실험 값 (정량, 문헌 풍부) |

제안: **수지상 세포 + CCL21** — 기존 세포 상태를 쓰고, 사용자가 말한 "케모카인 국소 고농도" 를 바로 다루며, 정성 판정 장치(관문 A′)가 이미 있다. 시냅스(전기)는 db 에 그 세계가 없어 처음부터 쌓아야 하므로 뒤로.
