# Phase 0 — 현실 검증 준비도 조사 (읽기 전용)

- 날짜: 2026-10-22
- 범위: 결정론 생물 엔진(`engine/fate_engine.js`)이 **현실 관찰에 맞춰 검증 가능한가** — 표현적·관측적 한계를 근거째로 지도화.
- 방법: **읽기 전용. 코드 0줄 수정. 테스트 실행 안 함** (따라서 "통과"라고 쓰지 않는다 — 테스트의 *존재*와 *주장*만 기록). 문서의 주장 ≠ 코드 사실 ≠ 테스트 주장을 가른다. 주장마다 `파일:줄`.
- 동기: 사용자 지적 — "맞는지 틀린지 관찰을 현실에 맞춰 검증이 불가능해서 아쉬웠다. 시뮬레이션이 현실 위에서 기능하게 하고 싶다."

## 0. 머리기사

지금 엔진은 **자기 자신에 대한 검사(self-consistency)** 는 15겹으로 촘촘하지만, **현실에 대한 동역학 검증(reality-anchored)** 은 사실상 0이다.

- 차등 이음새 15개 전부가 (a) 같은 알고리즘 두 구현의 일치, (b) 구성상 성립하는 보존 항등식, (c) **생물에 배선 안 된** P3–P5 모듈 안의 해석해 — 셋 중 하나다.
- 생물 경로의 현실 닻 = 관찰 **27개 중 검증용 5개, 전부 정성(qualitative)**. 정량 검증 관찰 = **0개**.
- 생물 엔진엔 **수렴 스윕 없음 · 해석해 궤적 벤치마크 없음 · 누적 hazard/사건시각 해석 벤치마크 없음**.

→ 막힌 곳은 통계 판정(이미 강함)도, 수치 무결성(이미 강함)도 아니라 **현실 닻 층**이다. 두 갈래로 비었다: ① 정량 **데이터**가 없고(IκBα 두 번의 벽), ② 관찰 연산자가 **측정의 눈먼 곳**을 아직 모델링하지 않는다.

| 공간 솔버 연결 | **없음.** 생물 경로가 `fv_solver·hmse·devs·fno·ood` 를 하나도 import 안 함 | grep 0 · `governance.test.mjs:299` |

**원리적으로 표현 못 하는 것 (= 표현적 한계):**
1. 구획 **안** 공간 기울기·미세도메인·국소밀도 의존 속도 (잘 섞인 가정이 배제).
2. MA/가역/MM 밖 속도 법칙.
3. 부분 구획 기하(시냅스·뗏목·응집점)를 "반응을 키우는 장소"로 — 지금은 별도 구획 + 수송 단계로 우회하거나 Gap 등록.

**단, 지금까지 검증한 생물(MHC I·II·텔로미어·CD8 운명)은 전부 잘 섞인 구획으로 충분했고**, 미세도메인이 결정적인 계는 아직 안 건드렸다. L000113(LPS→TNF 못 돌림)은 표현적 한계가 아니라 **수치적 한계**(42종 강성 연쇄, 모의 60초 > 벽시간).

## 2. 차등 이음새 지도 — 무엇을 현실과 맞대는가

15개 이음새를 "무엇에 맞대나"로 분류:

| 분류 | 이음새 | 현실을 맞대나 |
|---|---|---|
| 같은 알고리즘 두 구현 | Rust↔JS 궤적/결정성(1-4,14,15), MHC JS=Rust | ❌ 자기 일치 |
| 구성상 성립 항등식 | 독립 질량·부분구조 원장(5), 기호미분=IR(6), 희소 LU 구조(7), 교란 독립 재구성(8) | ❌ 자기 일치 |
| 분포 2표본 검정 | 확률 앙상블 감사(9: 운명비율·FPT·Fano·SSA vs τ) | △ "기각 못 함"≠같음 |
| **해석해 — 그러나 배선 안 된 P3-P5 안** | 확산 커널(10, 1e-10), 열역학 detailed balance(11), FV 질량(12), 평형비 k_f/k_r(13, 2-5%) | ❌ 생물 경로 아님 |

핵심 근거: 질량 원장은 `judicial/verifier.js:49-108`(1e-14), 기호미분 `judicial/derivative.js:165-222`(1e-14), 교란 재구성 `judicial/perturb_audit.js:44-101`, 확률 앙상블 `judicial/stoch_audit.js`. 해석해 묶음은 `tests/rules.test.mjs:845-1010` 전부 **P3/P4/P5 필드 모듈용**(비배선).

**생물 엔진에 없는 것 (조사 확인):**
- **수렴 스윕 없음.** 유일한 기준-허용오차 비교는 `orchestrator.js:53 refScenario`(rtol 1e-9) 를 `tests/fate_suite.js:52,75` 에서 **한 번** 맞대 L2<1e-6 주장. rtol/atol/dt 를 ≥2단계 반감하며 수렴 차수를 재는 루프는 없음. `governance.test.mjs:237-239` 는 rtol 바꿔 **단계 수 증가만** 주장.
- **해석해 궤적 벤치마크 없음.** 정확 반응 적분 `n(1−e^{−kΔt})` 은 `fv_solver.js`(비배선)에만, 단일 종 해석적 지수감쇠와 대조 안 함.
- **누적 hazard ∫a dt / 사건시각 vs 해석 hazard 없음.** `cumDD` 는 질량 항등식(이음새 5)으로만 검사. 사건시각은 백엔드 간 `event_tol` 로만 대조, 알려진 FPT 분포와 대조 안 함.

## 3. 현실 검증 준비도 (관측 인벤토리)

관찰 27개 (코드 로드로 확인):

| 용도 \ 종류 | kinetic_constant | concentration | volume | qualitative | 계 |
|---|---|---|---|---|---|
| estimation (상수를 넣음) | 17 | 2 | 3 | 0 | **22** |
| validation (예측을 확인) | 0 | 0 | 0 | 5 | **5** |

- **정량 검증 관찰 = 0.** 현실 닻 5개 전부 정성. `kinetic_constant` 17개는 `predict → NaN`(실행에서 안 나옴, `obs_operator.js:54`) — 애초에 예측 불가.
- fate 경로의 모든 정량 검사는 **자기 일치**(재실행 해시 `dbtool.mjs:550`, 질량 재계산, L2 vs 더 조인 자기 기준).
- 시나리오 대부분 **가상 상수**. 코드 자신: *"증명서는 계산의 무결성을 증명할 뿐, 가상 상수의 생물학적 타당성을 증명하지 않는다"* (`process_report.js:205`).

**관찰 연산자 `obs_operator.js`** (현실↔시뮬 다리): 있다 — `calibrate`(identity/linear/table) + `predict` 4종(amount·concentration·fraction·event_time). `orchestrator.js:112,142` → `obs_compare`/`qual_compare` 로 배선됨. **빠진 것: 장치의 눈먼 곳**(검출 한계·포화·자유형↔결합형 미분해·±분해능). `predict` 가 정확한 숫자만 돌려줘, 현실이 못 주는 정밀도로 맞대게 됨.

## 6. 표현적·관측적 한계 정식 명세

**표현적 한계 (REPRESENTATIONAL):** 생물 엔진은 잘 섞인 구획 ODE+혼성확률, MA/가역/MM 전용. 구획 내 공간·국소밀도·비표준 속도법칙을 원리적으로 못 담음. 공간 기계는 있으나 비배선. → *실재하나, 현재 검증 대상 생물에선 아직 결정적 증거 없음.*

**관측적 한계 (OBSERVABILITY):** 정량 현실 검증 관찰 0개; 관찰 연산자에 장치 눈먼 곳 미모델; 생물 경로에 해석해 궤적/hazard 벤치마크·수렴 스윕 없음. → *이것이 "현실 검증 불가"의 직접 원인.*

**두 한계의 관계:** 표현적 한계가 **실제로 생물 결과를 틀리게 하는지** 는 관측적 장치(차등 벤치마크·현실 닻)가 있어야 가릴 수 있다. 그러므로 **관측적 층을 먼저 세운다** — 그래야 표현적 한계도 비로소 "잡힌다".

## 7. 결론 — 지금 고칠 것은 구현이 아니라 검증

1. **현실 검증은 4단 사슬**(① 측정 수집 ② 시뮬 상태 ③ 관찰 연산자 ④ 통계 판정) 중 ①④는 이미 강함(수집 기계·TOST·우연기준선·검증 세트), **③이 얇아** 막힌다.
2. **올바른 형태 = 관찰 연산자 완성**: 측정 유형마다 검증된 순수 연산자(시뮬→측정량, **native 해상도 + 눈먼 곳**), 맞댈 연산자 없으면 **등록된 관측 공백**. 사법·컴파일러 쪽, 엔진·db·인증 불변, 백엔드 중립.
3. **현실의 해상도로 예측한다**: 정밀 숫자가 아니라 현실이 주는 해상도(대개 정성·순서형)로 반박 가능하게. 이미 작동 중(텔로미어 우연 0.00, MHC P=0.00305).
4. **수치/모델 오차 분리 벤치마크**(해석해 단일반응 감쇠·알려진 FPT·수렴 스윕)를 **생물 경로에 배선** — 패턴은 P-모듈에 이미 있어 싸게 이식 가능.
